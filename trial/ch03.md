# 第 3 章 Transformer 详解

Transformer 是现代大语言模型（LLM）的基石。从 GPT、Llama 到 DeepSeek、Qwen，几乎所有主流大模型都建立在同一个骨架上：**自注意力（self-attention）+ 前馈网络（FFN）+ 残差连接 + 归一化层**，堆叠几十层而成。本章将从 RNN 的痛点出发，完整推导注意力机制，逐一拆解每个组件的原理与演进，横向对比从原始 Transformer 到 Llama 的架构变迁，最后从零实现一个约 150 行、可直接运行的迷你 GPT。学完本章，你应当能够：读懂任何一个现代 LLM 的模型代码，并估算它的参数量与训练计算量。

## 3.1 从 RNN 到注意力

### 3.1.1 RNN 的两大痛点

在第 2 章我们回顾了 RNN / LSTM 语言模型。它按时间步逐词处理序列：

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$$

这带来两个根本性问题：

1. **无法并行**。$h_t$ 依赖 $h_{t-1}$，训练时必须顺序计算 $n$ 个时间步。GPU 擅长大规模并行矩阵乘法，RNN 却把计算拆成一连串小步，硬件利用率极低。序列越长，训练越慢，而大模型恰恰需要在万亿 token 的长文本上训练。

2. **长程依赖衰减**。要让第 1000 步的隐状态"记住"第 1 步的信息，信息必须经过 999 次矩阵乘法与非线性压缩。即便有 LSTM 的门控机制，梯度在时间上反向传播时仍会发生指数级衰减或爆炸（通过连乘 $\prod_t W_{hh}$），远距离的依赖很难学到。

此外，RNN 的隐状态是一个固定维度的向量，相当于用一个"瓶颈"压缩整段历史，信息容量有限。

三个问题可以用一个统一视角理解：RNN 把"序列上的信息路由"与"时间上的计算调度"耦合在了一起——信息只能沿时间轴逐步流动，计算也只能沿时间轴逐步执行。要打破这两个耦合，就需要一种让任意两个位置直接交换信息的机制，同时把整个序列的计算组织成可以一次完成的大矩阵运算。这正是注意力做的事。

### 3.1.2 注意力的核心思想

注意力机制给出了一种完全不同的信息交换方式：**不要逐步传递信息，让序列中每个位置直接"看到"所有位置，按相关性加权取用信息**。

直觉上，处理句子"小猫追着球跑，它玩得很开心"中的"它"时，我们希望模型能直接把"它"与"小猫"关联起来，而不是指望一个隐状态把"小猫"的信息扛过若干时间步。注意力把这种"直接关联"变成了可微分的矩阵运算：

- 每个位置的信息汇聚不再依赖序列距离，任意两个位置的路径长度都是 $O(1)$；
- 整个序列的计算是一次大矩阵乘法，完美匹配 GPU。

2017 年，Vaswani 等人在论文 *Attention Is All You Need*（arXiv:1706.03762）中提出：干脆完全抛弃循环结构，只用注意力 + 前馈网络，即 **Transformer**。此后它统治了 NLP，进而统治了几乎所有模态。

## 3.2 注意力机制完整推导

### 3.2.1 Query / Key / Value 的直觉

注意力可以类比"软性字典查询"（soft dictionary lookup）：

- **Query（查询，Q）**：当前位置"我想找什么信息"；
- **Key（键，K）**：每个位置"我能提供什么信息"的索引；
- **Value（值，V）**：每个位置实际携带的内容。

普通字典是硬查询：用 key 精确匹配，返回唯一 value。注意力是软查询：用 Query 与所有 Key 计算相似度，相似度越高，对应的 Value 被取用的权重越大，最终返回所有 Value 的加权平均。

> 📌 注："软性字典查询"是理解 Q/K/V 的最常用类比，但别把它看得太死：字典的 key 匹配是精确等值，而注意力是基于向量相似度的加权检索，因此"查"的结果永远是全体条目的混合，只是权重悬殊时看起来像精确命中。想看更细的图解，推荐 Jay Alammar 的 [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) 与 3Blue1Brown 的 [Transformer 注意力可视化视频](https://www.3blue1brown.com/topics/neural-networks)；数学定义见维基百科 [Attention (machine learning)](https://en.wikipedia.org/wiki/Attention_(machine_learning)))。

具体地，对输入序列 $X \in \mathbb{R}^{n \times d_{\text{model}}}$（$n$ 个 token，每个是 $d_{\text{model}}$ 维向量），用三个可学习矩阵做线性投影：

$$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$$

其中 $W_Q, W_K \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$W_V \in \mathbb{R}^{d_{\text{model}} \times d_v}$。同一个 $X$ 生成三份角色，这就是"自注意力"——序列自己查询自己。

### 3.2.2 相似度打分与 softmax 归一化

计算第 $i$ 个位置的 Query $q_i$ 与第 $j$ 个位置的 Key $k_j$ 的相似度，最自然的方式是点积：

$$s_{ij} = q_i \cdot k_j = q_i^\top k_j$$

点积越大，方向越一致，相关性越强。也可以用加性注意力（小型前馈网络打分，Bahdanau 注意力的做法）或双线性，但点积可以写成一次矩阵乘法 $QK^\top$，工程上远更高效，因此成为标准。

把分数经过 softmax 归一化成权重：

$$a_{ij} = \frac{\exp(s_{ij})}{\sum_{t=1}^{n} \exp(s_{it})}, \quad \sum_j a_{ij} = 1,\ a_{ij} \ge 0$$

softmax 既保证权重非负且和为 1，又通过指数放大差距——相关的位置权重显著更高。输出是 Value 的加权和：

$$\text{output}_i = \sum_{j=1}^{n} a_{ij} v_j$$

### 3.2.3 缩放点积注意力

把上述过程合并成一个矩阵公式，就是著名的**缩放点积注意力（scaled dot-product attention）**：

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

形状变化一目了然：$Q \in \mathbb{R}^{n \times d_k}$，$K^\top \in \mathbb{R}^{d_k \times n}$，得分矩阵 $S = QK^\top \in \mathbb{R}^{n \times n}$；softmax 逐行归一化后右乘 $V \in \mathbb{R}^{n \times d_v}$，输出 $\mathbb{R}^{n \times d_v}$。

**为什么要除以 $\sqrt{d_k}$？—— 点积方差推导**

假设 $q$ 与 $k$ 的各分量是相互独立、零均值、单位方差的随机变量：$q_i, k_i \sim \mathcal{N}(0,1)$ 且相互独立。考察点积：

$$s = q^\top k = \sum_{i=1}^{d_k} q_i k_i$$

每一项 $q_i k_i$ 的期望与方差为：

$$\mathbb{E}[q_i k_i] = \mathbb{E}[q_i]\,\mathbb{E}[k_i] = 0, \qquad \mathrm{Var}(q_i k_i) = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = 1 \cdot 1 = 1$$

由独立性，方差可加：

$$\mathrm{Var}(s) = \sum_{i=1}^{d_k} \mathrm{Var}(q_i k_i) = d_k, \qquad \text{即标准差为 } \sqrt{d_k}$$

也就是说，**点积的量级随维度 $d_k$ 增长而增大**。当 $d_k = 128$ 时，点积标准差约为 11；训练初期得分矩阵元素动辄几十，softmax 会进入饱和区——个别位置拿到接近 1 的权重，其余接近 0，梯度几乎为零（softmax 饱和时梯度 $\partial a_{ij}/\partial s_{ij} = a_{ij}(1-a_{ij}) \to 0$），训练无法启动。除以 $\sqrt{d_k}$ 恰好把方差拉回 1，使 softmax 工作在梯度健康的区间。

**逐数字走一遍：2×2 的缩放点积注意力**

公式看着抽象，我们用能整除的最小例子——$n=2$ 个 token、$d_k = 2$——手算一次完整前向。设（数值特意取成对角矩阵，便于心算）：

$$Q = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix},\quad K = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix},\quad V = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$$

**第 1 步：得分** $S = QK^\top = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$（单位矩阵与自身相乘不变）。

**第 2 步：缩放**，除以 $\sqrt{d_k} = \sqrt{2} \approx 1.414$：

$$\frac{S}{\sqrt{2}} = \begin{pmatrix} 0.707 & 0 \\ 0 & 0.707 \end{pmatrix}$$

**第 3 步：逐行 softmax**。以第 1 行为例：$\exp(0.707) \approx 2.028$，$\exp(0) = 1$，归一化因子为 $3.028$，故

$$A = \begin{pmatrix} 0.670 & 0.330 \\ 0.330 & 0.670 \end{pmatrix}$$

直觉解读：token 1 的 Query 与自己的 Key 完全对齐（得分 0.707），与自己"最像"，因此分给自己 67% 的注意力、给 token 2 分 33%。

**第 4 步：加权取 Value**，$O = AV$。第 1 行输出：

$$o_1 = 0.670 \begin{pmatrix} 1 & 2 \end{pmatrix} + 0.330 \begin{pmatrix} 3 & 4 \end{pmatrix} = \begin{pmatrix} 1.66 & 2.66 \end{pmatrix}$$

$$O = \begin{pmatrix} 1.66 & 2.66 \\ 2.34 & 3.34 \end{pmatrix}$$

两个输出都偏向自己的 Value（第 1 行偏向 $(1,2)$、第 2 行偏向 $(3,4)$），但混入了对方的信息。**反向传播也可手推**：由 $\partial L/\partial V = A^\top (\partial L/\partial O)$，注意力权重矩阵直接决定"误差如何按权重比例分回各个 Value"——这正是练习 2 要求证明的雅可比性质。若去掉第 2 步的缩放（得分变为 1 与 0），权重变为 $(0.731, 0.269)$，看似差别不大；但当 $d_k = 128$、未缩放得分达到 ±30 时，softmax 输出会退化为 $(1, 0)$——缩放的意义正在于此。

**复杂度分析**

- 计算量：$QK^\top$ 是 $n \times d_k$ 乘 $d_k \times n$，约 $n^2 d_k$ 次乘加；乘 $V$ 同阶。总计算量 $O(n^2 d)$。
- 显存：得分矩阵 $n \times n$，显存 $O(n^2)$。

序列长度翻倍，注意力的计算与显存变成 4 倍——这就是所谓的**平方复杂度问题**，是长上下文的主要瓶颈（第 14 章 FlashAttention、KV cache 优化都为此而来）。相比之下，RNN 计算是 $O(nd^2)$、线性于 $n$，Transformer 用平方代价换来了并行与全局感受野。

给一个直观的数量对比：$d=4096$、$n=1024$ 时，注意力部分 FLOPs 约 $4n^2 d \approx 1.7 \times 10^{10}$，而每层线性投影约 $12nd^2 \approx 2 \times 10^{11}$，注意力仅占不到一成；但当 $n$ 涨到 $32\text{K}$（长文档），$4n^2 d \approx 1.7 \times 10^{13}$，反超投影的 $6.4 \times 10^{12}$ 数倍。这就是"短序列时注意力不贵、长上下文时注意力是主要矛盾"的定量解释，也是 Chinchilla 式短序列训练与长上下文外推（第 14 章）分而治之的原因。

另一个常被忽视的量是**softmax 的显存**：$n \times n \times h$ 的得分矩阵必须在显存中物化才能做反向传播（朴素实现）。$n = 32\text{K}$、$h = 32$ 头、FP16 下单个样本一层就是 $32\text{K} \times 32\text{K} \times 32 \times 2\,\text{B} = 64\,\text{GB}$——远超单卡显存。FlashAttention 的核心正是通过分块计算（tiling）避免物化整个 $n \times n$ 矩阵，把显存降回 $O(n)$，我们留到第 14 章推导。

## 3.3 多头注意力

### 3.3.1 公式

一组 QKV 只能学一种"关注模式"，而语言中的依赖是多样的：句法关系、指代共现、语义相似……**多头注意力（multi-head attention）**把 $d_{\text{model}}$ 维空间切分成 $h$ 个子空间，每个头独立做注意力，再拼接：

$$\mathrm{MultiHead}(X) = \mathrm{Concat}(\text{head}_1, \dots, \text{head}_h)W_O$$

$$\text{head}_i = \mathrm{Attention}(XW_Q^{(i)},\, XW_K^{(i)},\, XW_V^{(i)})$$

其中每个头的投影矩阵 $W_Q^{(i)}, W_K^{(i)} \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$d_k = d_{\text{model}}/h$（如 $d_{\text{model}}=512$、$h=8$ 时 $d_k=64$），输出投影 $W_O \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$。

### 3.3.2 为什么要多头

- **表达多样性**：不同头可以在不同子空间学到不同模式。可视化研究表明，训练后的模型中确实存在"关注前一个词""关注句法主干""关注标点/分隔符"等分工明确的头。
- **相当于集成**：$h$ 个小注意力并联再线性融合，比单个大注意力更稳定。
- **代价几乎为零**：$h \times d_k = d_{\text{model}}$，多头并不增加投影矩阵的总参数量与计算量，只是把同样大的矩阵切成 $h$ 份、各自产生 $n \times n$ 的得分矩阵。

注意头数并非越多越好：$d_k$ 太小时每个头的表达力不足。现代模型常用 $d_k = 64 \sim 128$。

### 3.3.3 实现

工程上不需要真的开 $h$ 组小矩阵，只需一次大投影再 `reshape`（见 3.11 节完整代码）：

```python
q = self.w_q(x).view(B, T, H, d_k).transpose(1, 2)  # (B, H, T, d_k)
k = self.w_k(x).view(B, T, H, d_k).transpose(1, 2)
v = self.w_v(x).view(B, T, H, d_k).transpose(1, 2)
att = (q @ k.transpose(-2, -1)) / math.sqrt(d_k)     # (B, H, T, T)
att = att.masked_fill(causal_mask[:, :, :T, :T] == 0, float("-inf"))
y = F.softmax(att, dim=-1) @ v                       # (B, H, T, d_k)
y = y.transpose(1, 2).contiguous().view(B, T, H * d_k)
return self.w_o(y)
```

### 3.3.4 注意力头到底学到了什么

训练好的 Transformer 中，把注意力权重矩阵画成热图（行 = query 位置，列 = key 位置），能观察到清晰的分工：有的头几乎只看前一个位置（学到类似 bigram 的局部依赖），有的头聚焦句首的"主题词"，有的头在标点或分隔符之间跳跃（分段），还有的头呈现"对角线略偏移"的模式（局部窗口，近似卷积）。据此有人提出"用注意力权重做可解释性分析"的思路，但需谨慎：注意力权重高不等于因果上重要。对本书更有价值的是一个工程结论：**大量头是冗余的**——这为推理时的头剪枝、以及 GQA 把 KV 头数从 $h$ 压到几组提供了经验依据。

## 3.4 因果掩码与自回归解码

语言模型是自回归的：第 $t$ 个词的概率只依赖前 $t-1$ 个词，$P(x_t \mid x_{<t})$。但注意力的得分矩阵是全连接的——每个位置能看到所有位置，包括"未来"。若不加以限制，训练时模型会直接"抄答案"（用下一个词预测自己），损失趋近于零却毫无生成能力。

解决办法是在 softmax 之前，把得分矩阵上三角（未来位置）置为 $-\infty$，即**因果掩码（causal mask）**：

$$S'_{ij} = \begin{cases} s_{ij} / \sqrt{d_k}, & j \le i \\ -\infty, & j > i \end{cases}$$

softmax 后 $\exp(-\infty) = 0$，未来位置的权重严格为零。这个 $n \times n$ 的下三角布尔掩码只需构造一次，可以缓存复用。

另一个用途是**填充掩码（padding mask）**：批内不同句子长度不一时，把填充位置的得分也置 $-\infty$，避免污染注意力。

### 3.4.1 训练并行、推理自回归

因果掩码让 GPT 训练时可以一次前向计算所有位置的损失（teacher forcing，即"教师"把真实前文喂给模型而不是模型自己生成的文本，训练始终以真实数据为条件），完美并行；推理时则逐 token 生成——每生成一个 token 就把它拼回输入再前向。这引出 KV cache（第 14 章详解）：由于 K、V 只依赖历史 token，已算过的可以缓存，每步只需计算新 token 的 Query。

> 📌 注：teacher forcing 一词借自 RNN 时代的教学惯例：训练时每一步的条件是**真实**的前缀而非模型自己的输出。它带来训练（并行、条件干净）与推理（条件里含有模型自己生成的 token，可能有错）之间的分布差异，即"exposure bias"问题，这也是第 13 章对齐阶段要在模型自身样本上重新评估对数概率的原因之一。参见维基百科 [Teacher forcing](https://en.wikipedia.org/wiki/Teacher_forcing)。

把训练与推理的计算量对比一下，能看清自回归的成本结构。训练时一次前向处理整个长度为 $n$ 的序列，每个 token 都产生梯度信号，计算密度极高；推理时生成 $n$ 个 token 需要 $n$ 次前向，若无 KV cache 每次都要重算全部历史，总计算量为 $\sum_{t=1}^{n} t \cdot O(d^2) = O(n^2 d^2)$；有 KV cache 时每次只算一个新 token 的 Q 与全部 K/V 的交互，降为 $O(n \cdot d^2)$。这就是为什么一切推理优化的第一步都是实现 KV cache——它把生成复杂度从平方降到线性，且不改任何数学语义。

### 3.4.2 交叉注意力一瞥

原始 Transformer 的解码器里还有第二种掩码语义：**交叉注意力（cross-attention）**中，Query 来自解码器，而 Key/Value 来自编码器的输出，因此不需要因果掩码（编码器输出对解码器全程可见），但保留 padding mask。理解这一点有助于看清"因果掩码约束的是同一序列内部的时间方向"，而跨序列注意力（翻译、多模态中视觉 token 到语言 token 的注入，第 16 章 LLaVA 的投影连接可视为其退化形式）则由信息流向决定是否需要掩码。

## 3.5 位置编码

注意力本身是**置换不变**的：打乱输入 token 顺序，注意力只是相应地重排输出，无法区分"猫追狗"和"狗追猫"。因此必须显式注入位置信息。

### 3.5.1 正弦位置编码

原始 Transformer 对第 $pos$ 个位置、第 $i$ 对维度使用不同频率的正弦/余弦：

$$PE_{pos, 2i} = \sin\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right), \qquad PE_{pos, 2i+1} = \cos\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$

频率从 $1$（$i=0$）到 $1/10000$（$i=d/2-1$）按几何级数递减，类似二进制计数器：低维高频振荡编码细粒度位置，高维低频编码粗粒度位置。优点：无需学习、理论上可外推到训练未见长度；$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性函数，隐含一定的相对位置信息。

后一点值得展开。对每一对相邻的 $(\sin,\cos)$ 维度，利用三角恒等式：

$$\begin{aligned} \sin(\omega(pos+k)) &= \sin(\omega\, pos)\cos(\omega k) + \cos(\omega\, pos)\sin(\omega k) \\ \cos(\omega(pos+k)) &= \cos(\omega\, pos)\cos(\omega k) - \sin(\omega\, pos)\sin(\omega k) \end{aligned}$$

即偏移 $k$ 之后的位置编码等于原编码左乘一个只依赖 $k$（不依赖 $pos$）的旋转矩阵。这意味着"偏移量 $k$"可以用一组固定的线性变换表达，为后续的 RoPE 埋下了数学伏笔——RoPE 正是把这一性质从"编码之间"搬到了"Q/K 向量之间"，使其直接进入注意力得分。

### 3.5.2 可学习位置编码

GPT-2 直接把位置嵌入做成可学习的 `nn.Embedding(max_len, d)`。简单有效，成为早期 GPT 系列标准做法；缺点是不能自然外推到训练长度之外，且与 token 嵌入相加的方式使位置与语义信息糅合。

### 3.5.3 旋转位置编码 RoPE（重点推导）

RoPE（Rotary Position Embedding，arXiv:2104.09864）是当前主流（Llama、Qwen、DeepSeek 等）。核心思想：**用旋转矩阵把绝对位置作用于 Q 和 K，而 Q 与 K 的内积自然只依赖相对位置**。

**复数视角**。把第 $m$ 个位置的查询向量 $q$ 的第 $i$ 对分量 $(q_{2i-1}, q_{2i})$ 视为复数 $q^{(i)} = q_{2i-1} + \mathrm{i}\, q_{2i}$。定义旋转：

$$\tilde{q}_m^{(i)} = q^{(i)} e^{\mathrm{i} m \theta_i}, \qquad \theta_i = 10000^{-2i/d}$$

同样 $\tilde{k}_n^{(i)} = k^{(i)} e^{\mathrm{i} n \theta_i}$。注意力得分用到的是内积，复数乘积的实部即二维点积：

$$\mathrm{Re}\!\left[\tilde{q}_m^{(i)}\, \overline{\tilde{k}_n^{(i)}}\right] = \mathrm{Re}\!\left[q^{(i)} \overline{k^{(i)}}\, e^{\mathrm{i}(m-n)\theta_i}\right]$$

**关键结论**：得分只依赖相对位置 $m - n$，与绝对位置 $m$、$n$ 各自为何无关。旋转编码因此兼具"绝对形式、相对性质"——实现上按绝对位置旋转，数学上表达相对距离。

**实数视角（矩阵形式）**。等价地，每对相邻维度做一个二维旋转：

$$\begin{pmatrix} \tilde{q}_{2i-1} \\ \tilde{q}_{2i} \end{pmatrix} = \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix} \begin{pmatrix} q_{2i-1} \\ q_{2i} \end{pmatrix}$$

**相对位置性质**。由上式，$\tilde{q}_m^\top \tilde{k}_n$ 只含 $m-n$，位置每增加 1，相当于在所有频率上多旋转一个角度。这使得模型对"距离"的建模平移不变：两个 token 相隔 5 步的交互模式在任何上下文位置都一致。

**实现**（分块形式，避免逐对循环）：

```python
def rope(x, theta_base=10000.0):           # x: (B, H, T, d_k)
    T, d = x.shape[-2], x.shape[-1]
    inv_freq = 1.0 / (theta_base ** (torch.arange(0, d, 2).float() / d))  # (d/2,)
    t = torch.arange(T).float()                       # 位置 (T,)
    freqs = torch.outer(t, inv_freq)                   # (T, d/2)
    cos, sin = freqs.cos(), freqs.sin()
    x1, x2 = x[..., 0::2], x[..., 1::2]                # 奇偶分块
    out = torch.empty_like(x)
    out[..., 0::2] = x1 * cos - x2 * sin              # 二维旋转
    out[..., 1::2] = x1 * sin + x2 * cos
    return out
```

只旋转 Q、K，不旋转 V。RoPE 的外推问题（训练 4K、推理 128K 时高频分量剧烈旋转）催生了 NTK-aware 缩放、YaRN 等外推方法（第 14 章）。

### 3.5.4 ALiBi 简述

ALiBi（Attention with Linear Biases）不走嵌入路线，直接在注意力得分上加线性惩罚：

$$s_{ij} \leftarrow s_{ij} - |i - j| \cdot \frac{m}{h}$$

其中 $m$ 是随头数递减的斜率（如 $2^{-8h/H}$）。距离越远惩罚越大，无需任何位置参数，外推性能好，被 BLOOM、MPT 等采用。与 RoPE 的区别：ALiBi 是加性偏置（作用于得分），RoPE 是乘性旋转（作用于 Q/K 向量本身）。

## 3.6 前馈网络（FFN）的演进

每个 Transformer 层在注意力之后有一个逐位置（position-wise）的两层前馈网络，对注意力汇聚来的信息做非线性变换，通常占模型约 $2/3$ 的参数量，被认为存储了大量事实知识：

$$\mathrm{FFN}(x) = W_2\,\sigma(W_1 x), \qquad W_1 \in \mathbb{R}^{d_{\text{ff}} \times d},\ W_2 \in \mathbb{R}^{d \times d_{\text{ff}}},\ d_{\text{ff}} = 4d$$

激活函数的演进：

- **ReLU**（原始 Transformer）：$\max(0, x)$。零区域梯度恒为 0，可能出现"死神经元"。
- **GELU**（GPT/BERT）：$x \cdot \Phi(x)$，其中 $\Phi$ 是标准正态 CDF。平滑可导，负值区域保留少量信息，常近似为 $0.5x\left[1 + \tanh\left(\sqrt{2/\pi}(x + 0.044715 x^3)\right)\right]$。
- **SwiGLU**（Llama 系列，arXiv:2002.05202）：引入门控（gating）结构，一路做激活当"门"，一路线性通过：

$$\mathrm{SwiGLU}(x) = W_2\left[\mathrm{Swish}(W_1 x) \odot (W_3 x)\right], \qquad \mathrm{Swish}(x) = x \cdot \sigma(\beta x)$$

其中 $\odot$ 为逐元素乘。Swish（SiLU）平滑且非单调，门控让网络学会动态抑制无关特征，实验上稳定优于 ReLU/GELU。

**为何隐藏维缩小 $\frac{2}{3} \times 4$？** SwiGLU 有三个矩阵（$W_1, W_2, W_3$）而普通 FFN 只有两个。为了保持参数量（进而保持总计算预算）与隐藏维为 $4d$ 的普通 FFN 相当，令：

$$3 \times (d \cdot d_{\text{ff}}) = 2 \times (d \cdot 4d) \implies d_{\text{ff}} = \frac{8}{3}d = \frac{2}{3} \times 4d \approx 2.67d$$

实际工程中再向上取整到硬件友好的倍数（如 256 的倍数）。Llama-7B（$d=4096$）取 $d_{\text{ff}} = 11008$，即 $\approx 2.69d$。

## 3.7 归一化：LayerNorm、RMSNorm 与 Pre/Post-LN

### 3.7.1 LayerNorm

BatchNorm 依赖批统计量，在变长序列与小 batch 大模型训练中不稳定。LayerNorm 对每个样本自身做归一化：

$$\mathrm{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta, \qquad \mu = \frac{1}{d}\sum_i x_i,\ \ \sigma^2 = \frac{1}{d}\sum_i (x_i - \mu)^2$$

统计量沿特征维计算，与 batch 和序列长度无关。

### 3.7.2 RMSNorm

Llama 等现代模型发现减均值并非必需，只用均方根缩放：

$$\mathrm{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon}} \odot \gamma$$

省去均值计算与偏置 $\beta$，计算量减少约 $20\%$~$30\%$，效果与 LayerNorm 相当，在大模型中已成为默认选择。

### 3.7.3 Post-LN vs Pre-LN

- **Post-LN**（原始 Transformer）：$x \leftarrow \mathrm{LN}(x + \mathrm{Sublayer}(x))$，LN 在残差相加之后。梯度需穿过每层的 LN，深模型训练不稳定，必须配 warmup。
- **Pre-LN**（GPT-2 起）：$x \leftarrow x + \mathrm{Sublayer}(\mathrm{LN}(x))$，LN 在子层之前。主干上是一条无阻隔的"恒等高速路"，梯度可直接回传，训练稳定得多，可省去 warmup；代价是层数很深时表征可能欠规范化。
- 进一步的 **Sandwich LN / Pre-LN + 最终 LN**（Llama：每层 Pre-RMSNorm，模型末端再加一个 RMSNorm）是当前主流。

用一个简化模型看两者的差别。把子层输出记为 $f(x)$，Post-LN 下第 $l+1$ 层输入是 $\mathrm{LN}(x_l + f(x_l))$，反向传播时梯度必须穿过 $L$ 个 LN 的雅可比；若每个 LN 的雅可比范数略小于 1（方差被归一化时常见），连乘后随深度指数衰减——这就是"Post-LN 不加 warmup 容易不收敛"的机制：训练初期权重未定型，LN 的缩放剧烈，连乘项不稳定。Pre-LN 下梯度含恒等路径 $\prod_l 1 = 1$（见 3.8 节），对深度天然免疫；其代价是各层输出的方差随深度缓慢累积（每层加一个子层输出），因此末端 LN（GPT-2 的 `ln_f`）不可省略，极深模型还需对残差初始化做 $\sqrt{L}$ 类缩放。

## 3.8 残差连接：梯度的视角

残差连接（residual connection）$y = x + F(x)$ 并非 Transformer 原创，但至关重要。从反向传播看：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\left(1 + \frac{\partial F}{\partial x}\right)$$

其中的"$1$"意味着**无论子层 $F$ 学到什么，梯度都有一条直通恒等路径回传**。对 $L$ 层堆叠的模型，梯度包含 $\prod_l (1 + \partial F_l / \partial x_l)$ 的展开式，恒等项保证总有一个不衰减的成分，缓解了深层网络的梯度消失。这使堆叠上百层成为可能（ResNet 的核心洞察在 Transformer 中同样成立）。

设计启示：主干应保持"干净"——这解释了 Pre-LN（把 LN 移入分支）、把位置信号通过残差注入等做法。某些scaled residual（如 $\sqrt{L}$ 缩放深层的残差初始化，DeepSeek 使用）进一步改善极深模型的稳定性。

## 3.9 三大架构：Encoder-Decoder、Decoder-only、Encoder-only

| 维度 | 原始 Transformer | GPT（decoder-only） | BERT（encoder-only） |
|---|---|---|---|
| 结构 | 6 层编码器 + 6 层解码器 | $N$ 层解码器堆叠 | $N$ 层编码器堆叠 |
| 注意力 | 编码器双向；解码器因果 + 交叉注意力 | 仅因果自注意力 | 双向自注意力 |
| 预训练目标 | 机器翻译（监督） | 自回归语言建模 $P(x_t\mid x_{<t})$ | 掩码语言建模（MLM，15% 遮词预测） |
| 位置编码 | 正弦 | 可学习 | 可学习 |
| 典型用途 | 翻译、seq2seq | 生成、对话、代码、推理 | 文本理解、分类、检索、编码器 |
| 代表 | 原论文、T5、BART | GPT-2/3/4、Llama、Qwen、DeepSeek | BERT、RoBERTa |

为什么最终 LLM 几乎都选择 decoder-only？(1) 自回归目标与生成任务完全一致，训练-推理同分布；(2) 每个位置都产生梯度信号，训练效率高（MLM 只有被遮位置有损失）；(3) 因果掩码天然适配 KV cache 等推理优化；(4) 大规模实验（GPT-3、Chinchilla）证明了其扩展性。

需要说明的是，三大架构并非绝对淘汰关系。T5、BART 保留编码器-解码器结构，在翻译、摘要等"输入长、输出也长"的任务上依然优秀；BERT 类编码器则统治了嵌入与检索场景（第 11 章评测、第 17 章检索增强都会用到）。"decoder-only 胜出"指的是在**通用生成式基座**这个赛道上：一条自回归预训练流水线产出的模型，通过提示就能覆盖理解与生成两类任务，省去了为每类任务定制架构的成本。

## 3.10 从 GPT-2 到 Llama：现代架构演进对比

| 组件 | GPT-2 (2019) | GPT-3 (2020) | Llama / Llama-2 (2023) | Llama-3 / Qwen2 / DeepSeek (2024+) |
|---|---|---|---|---|
| 归一化 | LayerNorm，Post-LN | LayerNorm，Pre-LN | RMSNorm，Pre-LN | RMSNorm，Pre-LN（+ QK-Norm 变体） |
| 位置编码 | 可学习绝对 | 可学习绝对 | RoPE | RoPE（+ YaRN 等外推） |
| 激活 | GELU | GELU | SwiGLU | SwiGLU |
| FFN 隐藏维 | $4d$ | $4d$ | $\approx \frac{8}{3}d$ | $\approx \frac{8}{3}d$ |
| 注意力 | MHA | MHA | MHA（Llama-2 70B 用 GQA） | GQA（Llama-3、Qwen）；MLA（DeepSeek-V2/V3） |
| 偏置 | 有 | 有 | 无（去掉所有 bias） | 多数无 |
| 词表 | 50257 (BPE) | 50257 | 32000 | 128K~256K |
| 头维 $d_k$ | 64 | 64/128 | 64~128 | 128 |
| 训练精度 | FP32 | FP16 混合 | BF16 | BF16 / FP8（DeepSeek-V3） |

三个值得展开的注意力变体：

- **MQA**（multi-query attention）：所有 Q 头共享一组 K/V，KV cache 缩小 $h$ 倍，但质量略降。
- **GQA**（grouped-query attention）：折中方案，把 $h$ 个 Q 头分成 $g$ 组，每组共享一套 K/V（Llama-3-70B：64 个 Q 头、8 组 KV 头，KV cache 缩小 8 倍）。
- **MLA**（multi-head latent attention，DeepSeek-V2/V3）：把 KV 压缩到低秩潜在向量再按需还原，KV cache 缩小一个数量级，同时保持质量（第 14 章再述）。

表中的其他演进也有清晰的成本-收益逻辑：**去掉偏置**（Llama 起几乎删光 bias）是因为 LN 之后偏置作用微弱、却增加访存与 kernel 开销；**扩大词表**（32K → 128K+）以嵌入参数为代价换取多语言压缩率，配合 15T 级 token 的训练量摊薄成本；**BF16 替代 FP16** 则纯粹为了训练数值稳定（第 6 章）。可以看到，现代架构设计的主旋律不是"发明新结构"，而是在多年消融实验沉淀下的候选组件中，按训练规模做预算最优的组合——这背后正是第 7 章 Scaling Laws 的方法论。

## 3.11 逐模块 PyTorch 实现：150 行最小 GPT

下面实现一个完整可运行的 decoder-only GPT（结构对齐 GPT-2 风格，Pre-LN）。依赖仅 `torch`。

### 3.11.1 模型组件

```python
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class CausalSelfAttention(nn.Module):
    """多头因果自注意力（Pre-LN 下使用）"""
    def __init__(self, d_model, n_head, dropout=0.1, max_len=1024):
        super().__init__()
        assert d_model % n_head == 0
        self.n_head, self.d_k = n_head, d_model // n_head
        self.qkv = nn.Linear(d_model, 3 * d_model)   # Q/K/V 一次投影
        self.proj = nn.Linear(d_model, d_model)      # 输出投影 W_O
        self.attn_drop = nn.Dropout(dropout)
        self.resid_drop = nn.Dropout(dropout)
        mask = torch.tril(torch.ones(max_len, max_len, dtype=torch.bool))
        self.register_buffer("mask", mask.view(1, 1, max_len, max_len))

    def forward(self, x):
        B, T, C = x.shape
        q, k, v = self.qkv(x).split(C, dim=2)
        # (B,T,C) -> (B, n_head, T, d_k)
        q = q.view(B, T, self.n_head, self.d_k).transpose(1, 2)
        k = k.view(B, T, self.n_head, self.d_k).transpose(1, 2)
        v = v.view(B, T, self.n_head, self.d_k).transpose(1, 2)
        att = (q @ k.transpose(-2, -1)) / math.sqrt(self.d_k)   # (B,H,T,T)
        att = att.masked_fill(~self.mask[:, :, :T, :T], float("-inf"))  # 因果掩码
        att = F.softmax(att, dim=-1)
        y = self.attn_drop(att) @ v                             # (B,H,T,d_k)
        y = y.transpose(1, 2).contiguous().view(B, T, C)        # 拼接多头
        return self.resid_drop(self.proj(y))

class MLP(nn.Module):
    """前馈网络：GELU 激活，隐藏维 4d（若换 SwiGLU 则取 8/3d）"""
    def __init__(self, d_model, dropout=0.1):
        super().__init__()
        self.fc = nn.Linear(d_model, 4 * d_model)
        self.proj = nn.Linear(4 * d_model, d_model)
        self.drop = nn.Dropout(dropout)

    def forward(self, x):
        return self.drop(self.proj(F.gelu(self.fc(x))))

class Block(nn.Module):
    """Pre-LN Transformer 块：x + Attn(LN(x))，然后 x + MLP(LN(x))"""
    def __init__(self, d_model, n_head, dropout=0.1):
        super().__init__()
        self.ln1 = nn.LayerNorm(d_model)
        self.attn = CausalSelfAttention(d_model, n_head, dropout)
        self.ln2 = nn.LayerNorm(d_model)
        self.mlp = MLP(d_model, dropout)

    def forward(self, x):
        x = x + self.attn(self.ln1(x))   # 残差 + 注意力子层
        x = x + self.mlp(self.ln2(x))    # 残差 + FFN 子层
        return x
```

### 3.11.2 顶层模型与生成

```python
class GPT(nn.Module):
    def __init__(self, vocab_size, d_model=384, n_head=6,
                 n_layer=6, block_size=256, dropout=0.1):
        super().__init__()
        self.block_size = block_size
        self.tok_emb = nn.Embedding(vocab_size, d_model)   # token 嵌入
        self.pos_emb = nn.Embedding(block_size, d_model)   # 可学习位置嵌入
        self.drop = nn.Dropout(dropout)
        self.blocks = nn.ModuleList(
            [Block(d_model, n_head, dropout) for _ in range(n_layer)])
        self.ln_f = nn.LayerNorm(d_model)                  # 末端归一化
        self.head = nn.Linear(d_model, vocab_size, bias=False)
        self.apply(self._init_weights)                     # 权重初始化

    def _init_weights(self, m):
        if isinstance(m, nn.Linear):
            nn.init.normal_(m.weight, mean=0.0, std=0.02)  # GPT-2 式小方差初始化
            if m.bias is not None:
                nn.init.zeros_(m.bias)
        elif isinstance(m, nn.Embedding):
            nn.init.normal_(m.weight, mean=0.0, std=0.02)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        assert T <= self.block_size, "序列超长"
        pos = torch.arange(T, device=idx.device)
        x = self.drop(self.tok_emb(idx) + self.pos_emb(pos))
        for blk in self.blocks:
            x = blk(x)
        x = self.ln_f(x)
        logits = self.head(x)                              # (B,T,vocab)
        loss = None
        if targets is not None:
            loss = F.cross_entropy(
                logits.view(-1, logits.size(-1)), targets.view(-1))
        return logits, loss

    @torch.no_grad()
    def generate(self, idx, max_new_tokens=100, temperature=1.0, top_k=None):
        """自回归生成：逐 token 预测并拼回输入"""
        for _ in range(max_new_tokens):
            idx_cond = idx[:, -self.block_size:]            # 截断到上下文窗口
            logits, _ = self(idx_cond)
            logits = logits[:, -1, :] / temperature         # 只取最后一步
            if top_k is not None:                           # top-k 采样
                v, _ = torch.topk(logits, top_k)
                logits[logits < v[:, [-1]]] = float("-inf")
            probs = F.softmax(logits, dim=-1)
            idx_next = torch.multinomial(probs, num_samples=1)
            idx = torch.cat([idx, idx_next], dim=1)         # 拼接回输入
        return idx

if __name__ == "__main__":
    torch.manual_seed(0)
    model = GPT(vocab_size=1000)
    x = torch.randint(0, 1000, (2, 32))                     # (batch, seq)
    logits, loss = model(x, targets=x.roll(-1, dims=1))     # 简单自监督示例
    print("参数量:", sum(p.numel() for p in model.parameters()))
    print("损失:", loss.item())
    print("生成形状:", model.generate(x[:, :5], 20).shape)
```

实现要点逐条说明：

1. **QKV 合并投影**：一个 `Linear(d, 3d)` 再 `split`，比三个矩阵各调一次更高效；多头切分用 `view + transpose` 而非真复制。
2. **掩码注册为 buffer**：`register_buffer` 使掩码随模型移动设备且不计入参数；`tril` 生成下三角，`~mask` 处填 $-\infty$。
3. **Pre-LN**：两个子层各自先过 LN，残差主干保持畅通（3.7.3 节）；末端再补一个 `ln_f`。
4. **初始化**：GPT-2 用 $\mathcal{N}(0, 0.02)$ 初始化线性与嵌入层，配合残差结构足够稳定；更深的模型需额外缩放（如残差投影按 $1/\sqrt{2L}$）。
5. **generate 的温度与 top-k**：除以温度控制随机性，top-k 截断长尾（第 2 章已讨论采样策略）。
6. **`x.roll(-1)`**：训练目标是右移一位的输入本身；实际训练请用第 4 章的分词器与正确的标签构造（`targets = ids[:, 1:]` 配 `logits[:, :-1]`）。

### 3.11.3 训练循环：让最小 GPT 真正学起来

为了验证模型正确性，补一个字符级训练循环——用一段内置文本，几行代码即可看到 loss 稳定下降：

```python
text = ("low low low lower newest widest low lower newest widest " * 200)
chars = sorted(set(text))
stoi = {c: i for i, c in enumerate(chars)}          # 字符级"分词"（见第 4 章）
data = torch.tensor([stoi[c] for c in text])

def get_batch(bs=32, block=64):
    ix = torch.randint(0, len(data) - block - 1, (bs,))
    x = torch.stack([data[i:i + block] for i in ix])
    y = torch.stack([data[i + 1:i + block + 1] for i in ix])  # 目标右移一位
    return x, y

model = GPT(vocab_size=len(chars), d_model=128, n_head=4,
            n_layer=2, block_size=64)
opt = torch.optim.AdamW(model.parameters(), lr=3e-4)

model.train()
for step in range(500):
    x, y = get_batch()
    _, loss = model(x, targets=y)
    opt.zero_grad(set_to_none=True)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 梯度裁剪
    opt.step()
    if step % 100 == 0:
        print(f"step {step}  loss {loss.item():.4f}")

model.eval()
print("".join(model.generate(x[:, :1], 100, temperature=0.8)[0].tolist()))
```

注意这里标签的构造是 `x` 与右移一位的 `y`——配合模型内部"每个位置的 logits 只由 $\le t$ 的 token 产生"（因果掩码），损失恰好是 $\sum_t -\log P(x_{t+1} \mid x_{\le t})$。梯度裁剪（第 6 章详述）用于防止早期异常大的梯度破坏训练。把语料换成 TinyStories 级别的小数据集、模型放大到 $d_{\text{model}}=768$，就能得到一个能讲简单故事的迷你 GPT（第 6 章实战）。

## 3.12 参数量、FLOPs 与显存的估算

### 3.12.1 参数量公式推导

设词表 $V$、维度 $d$、层数 $L$、FFN 系数 $c$（GPT-2 风格 $c=4$，SwiGLU 风格有效 $c=8/3$ 且 FFN 有三个矩阵）、最大序列长 $S$。逐项计算（忽略归一化层与偏置）：

**每层注意力**：
- QKV 投影：$3 \times d^2$（合并为一个 $d \times 3d$ 矩阵）
- 输出投影 $W_O$：$d^2$
- 小计：$4d^2$

**每层 FFN**：
- GELU FFN（两个矩阵，隐藏维 $4d$）：$2 \times 4d^2 = 8d^2$
- SwiGLU（三个矩阵，隐藏维 $\frac{8}{3}d$，见 3.6 节）：$3 \times (\frac{8}{3}d)^2 = \frac{64}{3}d^2 \approx 21.3d^2$

**嵌入与输出**：
- token 嵌入 $Vd$；输出投影通常与嵌入共享权重（weight tying），可省 $Vd$；位置嵌入 $Sd$（RoPE 则为 0）。

**总参数量**（取每层 $12d^2$、不共享词表权重）：

$$N \approx L \times 12d^2 + 2Vd + Sd$$

例：GPT-2 small（$d=768$，$L=12$，$V=50257$）。其主体为 $12 \times 12 \times 768^2 \approx 84.9\text{M}$；GPT-2 **共享输入嵌入与输出投影**（weight tying），词表部分只计一次 $50257 \times 768 \approx 38.6\text{M}$，再加位置嵌入 $1024 \times 768 \approx 0.8\text{M}$，合计 $\approx 84.9 + 38.6 + 0.8 \approx 124\text{M}$，与官方 124M 吻合（若不共享则应约为 162M）。Llama-2 7B（$d=4096$，$L=32$，$V=32000$）：$32 \times 12 \times 4096^2 + 2 \times 32000 \times 4096 \approx 6.4\text{B} + 0.26\text{B} \approx 6.7\text{B}$；Llama 未共享嵌入，且 FFN 用 SwiGLU 略大于 $8d^2$（11008 而非 $8/3 \cdot 4096 \approx 10923$），合计正好约 7B。经验法则：**主体参数 $\approx 12Ld^2$**，FFN 与注意力约各占 $2/3$ 与 $1/3$。

### 3.12.2 训练 FLOPs：$6ND$ 的推导

前向传播中，参数量为 $N$ 的模型，每个参数对应输入上约一次乘加（一个 $d \times d$ 矩阵乘对每 token 恰好用每个参数一次），故每 token 前向 FLOPs $\approx 2N$（一次乘 + 一次算 2 FLOPs）。

反向传播需要计算对输入和对权重两组梯度，计算量约为前向的 2 倍：每 token 反向 $\approx 4N$。

总训练计算量（$D$ 为训练 token 数）：

$$C \approx \underbrace{2ND}_{\text{前向}} + \underbrace{4ND}_{\text{反向}} = 6ND$$

例：Llama-2 7B 训练 2T token：$6 \times 6.7 \times 10^9 \times 2 \times 10^{12} \approx 8 \times 10^{22}$ FLOPs，与论文报告的 $8.4 \times 10^{22}$ 吻合。注意注意力得分矩阵的计算 $O(n^2 d)$ 在长序列时是额外项，上式忽略之（短序列时占比小）。

### 3.12.3 KV cache 显存公式（预告）

推理时缓存每层所有历史 token 的 K 与 V。对层数 $L$、KV 头数 $h_{kv}$（GQA 下小于 $h$）、头维 $d_k$、序列长 $n$、batch $B$、每个元素 $p$ 字节（FP16 为 2）：

$$\text{KV cache} = 2 \times L \times h_{kv} \times d_k \times n \times B \times p$$

例：Llama-2-7B（$L{=}32$，$h_{kv}{=}32$，$d_k{=}128$），FP16、batch 1、$n{=}4096$：$2 \times 32 \times 32 \times 128 \times 4096 \times 2 \approx 2.1$ GB——batch 1 就要 2 GB，再乘以并发数很容易吃满显存。三个缓解手段与该公式一一对应：**缩 $h_{kv}$**（GQA：Llama-2-70B 取 $h_{kv}=8$，直接省 8 倍；MLA 用低秩压缩省得更多）、**缩 $p$**（KV cache 量化到 INT8 甚至 FP4，第 14 章）、**缩 $n$**（滑动窗口注意力等）。注意 KV cache 与 batch、序列长度的乘积关系也解释了为什么长上下文服务的并发能力骤降——这是第 15 章显存容量规划的核心约束。

## 3.13 常见误区辨析

初学者实现 Transformer 时最容易踩的坑，在此集中列出：

1. **忘记除以 $\sqrt{d_k}$**。小数据集上往往"也能训"，掩盖了 softmax 饱和问题；数据一大 loss 就不动了。缩放因子必须与每头维度 $d_k$ 对应，而不是 $d_{\text{model}}$。
2. **多头切分用错维度**。`view(B, T, H, d_k)` 后必须 `transpose(1, 2)` 把头维提前，否则"多头"退化成对特征维的错误分组；拼接时记得 `contiguous().view(B, T, C)`。
3. **掩码方向搞反**。因果掩码是**下三角**可见（`tril`），填 $-\infty$ 的位置是"未来"。调试时打印一行权重，应看到位置 $t$ 之后全为 0。
4. **Pre-LN 与 Post-LN 的层归一化位置写混**，或漏掉末端 `ln_f`。
5. **RoPE 只旋转 Q/K，不旋转 V**；且推理时缓存的历史 K 必须在缓存前就完成旋转，否则每步的坐标系不一致。
6. **训练目标与输入错位**：标签必须是右移一位的序列，`logits[:, :-1]` 对 `targets = ids[:, 1:]`，直接拿 `ids` 当自己的标签会让模型学到恒等映射且损失虚低。

## 本章小结

- RNN 的顺序计算与长程梯度衰减催生了注意力：**所有位置两两直接交互，一次矩阵乘法完成**。
- 缩放点积注意力 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$；除以 $\sqrt{d_k}$ 是因为独立分量点积的方差为 $d_k$，不缩放会使 softmax 饱和、梯度消失。复杂度 $O(n^2 d)$，长序列平方膨胀是主要瓶颈。
- 多头注意力以零额外参数代价在多个子空间学习不同交互模式。
- 因果掩码把未来位置得分置 $-\infty$，使训练可并行、推理可自回归。
- 位置信息必须显式注入：正弦编码免学习、可学习编码简单、**RoPE 用旋转把绝对位置编码进 Q/K 而内积只依赖相对位置**，是当前标准；ALiBi 用线性距离惩罚替代。
- FFN 占参数大头，激活从 ReLU→GELU→SwiGLU，SwiGLU 三矩阵因此隐藏维取 $\approx \frac{8}{3}d$ 以对齐参数预算。
- 归一化从 Post-LN 演进到 Pre-RMSNorm，配合残差恒等路径，让百层模型可训。
- 架构上 decoder-only 胜出；GPT-2 到 Llama 的演进主线：RMSNorm、RoPE、SwiGLU、GQA、无 bias、大词表。
- 估算工具箱：参数 $N \approx 12Ld^2 + 2Vd$；训练 FLOPs $C = 6ND$；KV cache $= 2Lh_{kv}d_k n B p$ 字节。

## 练习

### 实操：编程练习

**练习 A：从零实现缩放点积注意力，并与官方实现对账。** 用 3.2.3 节手算例子的思想，写一个支持（可选）因果掩码的注意力，数值验证与 `torch.nn.functional.scaled_dot_product_attention` 完全一致。

```python
import torch
import torch.nn.functional as F
import math

def attention(Q, K, V, causal=False):
    """朴素实现：Q,K,V: (B, H, T, d_k) -> (B, H, T, d_k)"""
    d_k = Q.size(-1)
    att = Q @ K.transpose(-2, -1) / math.sqrt(d_k)        # (B,H,T,T) 缩放点积
    if causal:                                            # 上三角(未来)置 -inf
        T = Q.size(-2)
        mask = torch.tril(torch.ones(T, T, dtype=torch.bool, device=Q.device))
        att = att.masked_fill(~mask, float("-inf"))
    return F.softmax(att, dim=-1) @ V

torch.manual_seed(0)
Q, K, V = (torch.randn(2, 4, 8, 16) for _ in range(3))     # B=2, H=4, T=8, d_k=16
out_naive = attention(Q, K, V, causal=True)
out_official = F.scaled_dot_product_attention(Q, K, V, is_causal=True)
print("max |diff| =", (out_naive - out_official).abs().max().item())
# 预期输出：max |diff| ≈ 1e-6 量级（浮点误差内），两实现等价
# 官方版本内部会自动选择 FlashAttention 等 kernel——数学相同、显存与速度更优
```

**练习 B：数值验证因果掩码"看不见未来"。** 对比有/无因果掩码时各位置的输出：无掩码时改变未来 token 会影响历史位置的输出，有掩码时则完全不受影响。

```python
import torch, torch.nn.functional as F, math

torch.manual_seed(0)
Q, K, V = (torch.randn(1, 1, 6, 8) for _ in range(3))      # T=6, d_k=8

def attn(Q, K, V, causal):
    att = Q @ K.transpose(-2, -1) / math.sqrt(Q.size(-1))
    if causal:
        T = Q.size(-2)
        att = att.masked_fill(
            ~torch.tril(torch.ones(T, T, dtype=torch.bool)), float("-inf"))
    return F.softmax(att, dim=-1) @ V

K2, V2 = K.clone(), V.clone()
K2[0, 0, 2] += 10.0                                        # 篡改"未来"(位置2)
V2[0, 0, 2] += 10.0

out_a, out_b = attn(Q, K, V, causal=True), attn(Q, K2, V2, causal=True)
diff_causal = (out_a[0, 0, :2] - out_b[0, 0, :2]).abs().max().item()
print(f"因果掩码下，位置0/1 输出受未来篡改影响: {diff_causal:.2e}")  # 预期 0.00e+00

out_c, out_d = attn(Q, K, V, causal=False), attn(Q, K2, V2, causal=False)
diff_full = (out_c[0, 0, :2] - out_d[0, 0, :2]).abs().max().item()
print(f"无掩码时，位置0/1 输出受未来篡改影响: {diff_full:.3f}")     # 预期 > 0（未来泄漏）
```

**练习 C：用 autograd 验证注意力反向传播。** 3.2.3 节末提到 $\partial L/\partial V = A^\top(\partial L/\partial O)$、且 softmax 梯度为 $a_{ij}(1-a_{ij})$。用 PyTorch 的自动微分数值确认这两条性质。

```python
import torch, torch.nn.functional as F, math

torch.manual_seed(0)
Q = torch.eye(2)                                    # 复用 3.2.3 节 2×2 手算例子
K = torch.eye(2).requires_grad_(True)
V = torch.tensor([[1., 2.], [3., 4.]], requires_grad=True)

S = Q @ K.T / math.sqrt(2)
A = F.softmax(S, dim=-1)                            # 权重矩阵 A
O = A @ V
G = torch.tensor([[1., 0.], [0., 1.]])              # 假设 dL/dO = I
O.backward(G)

print("A =", A)                                     # 预期 [[0.670,0.330],[0.330,0.670]]
print("解析解 AᵀG =", (A.T @ G))                     # ∂L/∂V 的解析式
print("autograd  ∂L/∂V =", V.grad)                   # 两者应逐元素相等
assert torch.allclose(V.grad, A.T @ G, atol=1e-6)
# 再验证 softmax 梯度：p(1-p)。对第 1 行 logit (0.707, 0)，p0 = 0.670
a = torch.tensor(0.707, requires_grad=True)
torch.softmax(torch.stack([a, torch.tensor(0.)]), 0)[0].backward()
print(f"softmax 梯度 = {a.grad:.4f} (期望 ≈ {0.670*(1-0.670):.4f})")  # ≈ 0.221
```
