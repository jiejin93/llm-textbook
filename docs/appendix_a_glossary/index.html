    术语（中文） 英文 一句话定义与作用
    Transformer Transformer 完全基于注意力、可完全并行的序列建模架构，大模型的骨架 → ch06
    自注意力 self-attention 序列内每个位置对其他位置加权汇聚，建模任意距离的依赖 → ch06
    缩放点积注意力 scaled dot-product attention \(\mathrm{softmax}(QK^\top/\sqrt{d_k})V\)，除以 \(\sqrt{d_k}\) 防内积过大致梯度消失 → ch06
    查询/键/值 Q / K / V 三组线性投影：相似度由 QK 决定，内容信息由 V 携带 → ch06
    注意力权重 attention weights softmax 后的分布，表示"每个位置该看谁多少" → ch06
    注意力头 attention head 一组独立 Q/K/V 投影，各自关注不同子空间的模式 → ch06
    多头注意力 MHA (Multi-Head Attention) 并行多个头再拼接，让模型同时捕捉多种关系 → ch06
    多查询注意力 MQA (Multi-Query) 所有头共享一组 K/V，大幅压缩 KV cache 但略损精度 → ch08
    分组查询注意力 GQA (Grouped-Query) 分组共享 K/V，MHA 与 MQA 的折中，主流开源模型标配 → ch08
    多头潜在注意力 MLA (Multi-head Latent Attention) 低秩投影把 KV 压进共享潜向量，DeepSeek 系的显存优化 → ch08
    键值缓存 KV cache 缓存历史 token 的 K/V 避免每步重算，自回归解码提速的关键 → ch15
    位置编码 positional encoding 为天然无序的注意力注入 token 位置信息 → ch05
    正弦位置编码 sinusoidal PE 用不同频率三角函数编码绝对位置，可外推到训练外长度 → ch05
    可学习位置编码 learned PE 位置向量当作可训练参数，简单但无法外推 → ch05
    旋转位置编码 RoPE (Rotary PE) 把相对位置以旋转矩阵作用在 Q/K 上，主流长文本方案 → ch05
    RoPE 底数 RoPE base / theta 控制旋转频率谱的底数（如 1e4→1e6），调大利于长上下文外推 → ch05
    线性偏置注意力 ALiBi 按距离对注意力分数线性惩罚，无需训练即可外推更长序列 → ch05
    相对位置编码 relative PE 在注意力内部加位置偏置，与绝对位置解耦 → ch05
    NTK 感知缩放 NTK-aware scaling 修改 RoPE 底数而非线性缩放位置，保住高频相对位置不失真 → ch05
    YaRN YaRN NTK 缩放 + 注意力温度修正的高效上下文扩展方法 → ch08
    因果掩码 causal mask 上三角置 \(-\infty\) 屏蔽未来 token，让自回归训练可并行 → ch06
    滑窗注意力 sliding-window attention (SWA) 只看最近 W 个 token，KV cache 与计算复杂度线性化 → ch08
    注意力汇聚 attention sink 开头 token 吸走大量注意力权重的现象，流式推理不可丢弃它们 → ch15
    原生稀疏注意力 NSA (Native Sparse Attention) 硬件对齐、可训练的原生稀疏注意力（DeepSeek）→ ch08
    块注意力混合 MoBA (Mixture of Block Attention) 以块为单位路由查询的稀疏注意力（Moonshot）→ ch08
    线性注意力 linear attention 用核函数近似 softmax 使复杂度降为 \(O(T)\)，长序列友好但精度有损 → ch08
    状态空间模型 SSM (State Space Model) 用线性递推的隐状态压缩历史，推理时每步常数内存 → ch08
    Mamba Mamba 选择性 SSM（参数随输入变化），线性复杂度挑战 Transformer → ch08
    RWKV RWKV 把注意力改写为可并行训练的 RNN 形式，推理常数内存 → ch08
    xLSTM xLSTM 扩展 LSTM（指数门控、矩阵记忆）的序列建模新尝试 → ch08
    混合架构 hybrid architecture 注意力层与线性层交替堆叠，兼顾质量与推理成本 → ch08
    前馈网络 FFN / MLP 逐位置的两层全连接与激活，承担参数大头与知识存储 → ch06
    SwiGLU SwiGLU SiLU 门控的 FFN 变体，同参数量下优于 ReLU/GELU → ch07
    GELU GELU 平滑的类 ReLU 激活函数，BERT/GPT 早期常用 → ch03
    残差连接 residual connection 跨层相加的旁路，让深层网络可训练 → ch03
    层归一化 LayerNorm 按特征维归一化再仿射，稳定深层训练 → ch03
    均方根归一化 RMSNorm 去掉均值中心化的 LayerNorm，计算更省，LLaMA 系标配 → ch07
    前置归一化 Pre-LN 归一化放残差分支入口，梯度稳定、深层好训 → ch03
    后置归一化 Post-LN 归一化放残差出口，原始 Transformer 设计，深层难训 → ch03
    QK 归一化 QK-Norm 对 Q/K 做归一化抑制注意力 logits 爆炸，训练稳定化手段 → ch10
    logits 软限幅 logit soft-capping 把注意力/输出 logits 压到阈值内防数值溢出（Gemma-2 采用）→ ch10
    随机失活 dropout 训练时随机置零激活做正则；大规模预训练常设为 0 → ch03
    隐藏维度 hidden size / \(d_{\text{model}}\) 每层向量宽度，是参数量与显存估算的基本量 → ch06
    混合专家 MoE (Mixture of Experts) 每层多个专家 FFN、每 token 只激活部分，扩容量不扩算力 → ch09

    共享专家 shared expert 所有 token 必经的专家，吸收共性知识 → ch09

    术语（中文） 英文 一句话定义与作用
    自回归建模 autoregressive modeling 用"预测下一个 token"分解联合概率，生成即逐步采样 → ch06
    教师强制 teacher forcing 训练时用真实前缀而非模型自身输出，保证并行与稳定梯度 → ch06
    交叉熵 cross-entropy 衡量预测分布与真实标签差异的损失，语言建模的默认目标 → ch02

    温度 temperature logits 除以 \(T\) 再 softmax：\(T<1\) 更确定、\(T>1\) 更多样 → ch15
    贪心解码 greedy decoding 每步取最大概率 token，稳定但易重复呆板 → ch15

    重复惩罚 repetition penalty 降低已出现 token 的 logits，抑制复读 → ch16
    出现/频率惩罚 presence / frequency penalty 对出现过的 token 整体或按次数惩罚 → ch16
    分数偏置 logit bias 对指定 token 加/减固定分数做硬控制 → ch16
    停止条件 stop condition 命中 EOS、停止串或长度上限即终止生成 → ch16
    采样参数 sampling params temperature/top-p 等控制生成随机性的旋钮，需按任务调整 → ch16
    序列级评分 sequence-level scoring 对完整输出计算平均对数概率等指标，用于候选重排 → ch19
