前言

为什么写这本书

2020 年前后，如果你问一位深度学习工程师”语言模型能做什么”，得到的答案多半是”补全句子、做翻译、写摘要”。而今天，大语言模型（Large Language Model, LLM）已经能够编写可运行的程序、推导数学证明的步骤、阅读图表回答问题，甚至作为智能体（Agent）自主调用工具完成复杂任务。这一变化的核心，是一条看似简单到令人怀疑的路径：在海量文本上，训练一个预测下一个词的神经网络。

正是这条路径的”简单”与效果的”惊人”之间的巨大反差，使得许多掌握了深度学习基础的开发者产生了同样的困惑：

  • 我懂 CNN、RNN、反向传播，也写过 PyTorch，但为什么就是看不懂 Transformer 论文里的 Q、K、V 到底在做什么？
  • 网上的教程要么停留在”十行代码实现 GPT”，要么直接跳到”用 vLLM 起一个服务”，中间的预训练数据工程、分布式训练、RLHF 后训练去哪里学？
  • 想动手训练一个自己的模型，从哪里获得数据、需要多少显存、怎么评估效果、又怎么量化压缩后部署上线？

市面上的资料大致分两类：一类是学术论文与前沿技术报告，默认读者已经掌握全部背景；另一类是框架使用教程，教你调用 API 却不解释背后的原理。缺的是一本介于两者之间、把”从 Transformer 结构”到”生产环境部署”完整贯通的系统性教材。 这本书就是为了填补这个空缺。

这本书讲什么

本书的书名已经概括了主线：从 Transformer 到部署。全书共 17 章，分为六个部分，沿着”一个 LLM 是如何被造出来并投入使用”的完整生命周期展开：

  1. 基础（第 1–4 章）：语言建模的概率视角、Transformer 的逐模块剖析与最小可运行实现、分词器（BPE 等）。
  2. 预训练（第 5–9 章）：数据清洗与去重、优化器与训练稳定性、Scaling Laws、数据/张量/流水线等分布式训练、混合专家模型（MoE）。
  3. 微调与评测（第 10–11 章）：SFT 与 LoRA/QLoRA、主流评测基准与评测方法论。
  4. 后训练与强化学习（第 12–13 章）：策略梯度与 PPO 的完整推导、RLHF 三阶段、DPO、GRPO 与推理模型（R1 式）训练。
  5. 推理与部署（第 14–15 章)：KV Cache、FlashAttention、PagedAttention 与 vLLM、各类量化方法（GPTQ/AWQ/FP8）、服务化与监控。
  6. 多模态与前沿（第 16–17 章）：ViT、CLIP、LLaVA 式视觉语言模型的设计与训练、推理模型与 Agent 等前沿专题。

本书不满足于”讲清楚是什么”，而是力求让你在合上书后能够独立完成：读懂一份现代 LLM 的架构代码并指出它与 GPT-2 的差异；规划一次预训练或微调的显存与算力；选择并实现合适的评测；用 RLHF/DPO/GRPO 做对齐；用量化和推理引擎把模型部署成高吞吐服务。

读者画像与先修要求

本书假设你已经具备一门”深度学习入门课”的水平，具体来说：

  • 理解神经网络的前向传播与反向传播（Backpropagation），能手推简单网络的梯度；
  • 用过 PyTorch，会写训练循环（forward → loss → backward → step）、会搭 nn.Module；
  • 了解 CNN 与 RNN/LSTM 的基本思想——本书会在第 2 章快速回顾神经语言模型，但不会从”什么是神经网络”讲起；
  • 具备基础的线性代数（矩阵乘法、softmax）、概率论（条件概率、期望）与微积分知识。

你不需要已经了解 Transformer、注意力机制或任何 LLM 训练细节——这些正是本书要教给你的。

如果你符合上述画像，本书的难度曲线是为你设计的：第 3 章（Transformer 详解）与第 8 章（分布式训练）是全书最陡的两段爬坡，我们会用大量图示、逐行代码和数值例子帮你过关。

  • 应用工程师路线：第 1–3 章 → 第 4 章 → 第 10 章 → 第 14–15 章。目标是”会用、会微调、会部署”，可以暂缓分布式训练与 RL 理论。

如何使用本教材

配套代码。 本教材的口号是”每个关键概念都有可运行的代码”。书中所有代码块均可在配套仓库中找到完整版本（含训练脚本、数据下载与依赖清单），读者可以在本地 GPU、实验室服务器或 Colab 上复现。代码风格遵循三个原则：优先正确与可读，其次才是性能；每个超参数显式写出，不藏在配置文件深处；与工业界主流实现（如 nanoGPT、HuggingFace Transformers）对照给出链接，帮你从”教材代码”过渡到”生产代码”。

练习。 每章末尾的练习分为三类：概念题（检验理解）、编程题（动手实现）、思考题（没有标准答案，训练科研品味）。强烈建议至少完成编程题——LLM 是一门实践学科，看懂与写出来之间隔着一条鸿沟。

阅读方法。 第一遍读可以跳过所有推导，只看图、代码与小结；第二遍精读公式推导（尤其是第 3 章注意力机制、第 12–13 章强化学习部分），建议拿纸笔跟随；第三遍把书当手册查阅。数学 notation 全书统一，附录 A 提供符号表，附录 C 提供术语中英对照表。

硬件说明。 第 3、6、10、14 章的实战代码在单张 24 GB 显存的消费级 GPU（如 RTX 4090）上即可运行；第 8、9 章的分布式实验可用云上多卡环境或以阅读分析为主。没有 GPU 的读者可以使用 Google Colab（免费提供 T4 显卡）或国内 AutoDL 等算力平台。
