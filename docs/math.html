0.2 线性代数：向量、矩阵与张量

0.2.1 向量：一串数字，也是一个点

直觉：向量（vector）就是一列有序的数，比如 x=(x1,x2,…,xd)∈Rd\mathbf{x} = (x_1, x_2, \ldots, x_d) \in \mathbb{R}^dx=(x1​,x2​,…,xd​)∈Rd。它有两种等价的看法：一是一支从原点出发的箭头（有方向有长度），二是 ddd 维空间里的一个点。大模型里，“猫”这个词在模型眼中就是一个几千维的向量——语义被编码成了空间中的位置。

定义：ddd 维实数向量空间 Rd\mathbb{R}^dRd 中的元素。向量可以相加（对应分量相加）、可以数乘（每个分量乘同一个数）。

q⋅k=∑i=1dqiki=∥q∥ ∥k∥cos⁡θ \mathbf{q} \cdot \mathbf{k} = \sum_{i=1}^{d} q_i k_i = \|\mathbf{q}\| \, \|\mathbf{k}\| \cos\theta q⋅k=i=1∑d​qi​ki​=∥q∥∥k∥cosθ

其中 θ\thetaθ 是两向量的夹角。直觉：点积衡量“两个向量有多一致”。方向相同 → 点积大且为正；垂直（无关）→ 为 0；相反 → 为负。在词向量空间里，“国王”与“女王”两个向量的点积，会远大于“国王”与“洗衣机”的点积。

0.2.5 PyTorch 张量与广播

张量（tensor）是向量的推广：0 阶=标量，1 阶=向量，2 阶=矩阵，3 阶以上=张量。一批句子的词向量堆在一起就是形状 (batch, seq_len, d_model) 的 3 阶张量。广播（broadcasting）是 numpy/PyTorch 的对齐规则：形状不同的张量运算时，维度从右往左对齐，长度为 1 的维度自动“复制”到与另一方相同。→ 第 3 章多头注意力的 mask、第 8 章分布式里的 per-device 缩放，全靠广播。

0.3 概率论：不确定性的语言

0.3.1 随机变量与概率分布

直觉：随机变量（random variable）是“还没揭晓的数”——掷骰子的点数、模型下一个要生成的词。概率分布（probability distribution）给每个可能的结果分配一个 0 到 1 的权重，所有权重加起来等于 1。语言模型本质上就是一台机器：输入前文，输出“下一个词的概率分布”。

定义：离散随机变量 XXX 取值 xxx 的概率记 P(X=x)P(X = x)P(X=x)（简写 p(x)p(x)p(x)），满足 p(x)≥0p(x) \ge 0p(x)≥0 且 ∑xp(x)=1\sum_x p(x) = 1∑x​p(x)=1。

0.3.2 联合、条件概率与贝叶斯

  • 联合概率 P(A,B)P(A, B)P(A,B)：两件事同时发生的概率。
  • 条件概率：P(A∣B)=P(A,B)P(B)P(A \mid B) = \dfrac{P(A, B)}{P(B)}P(A∣B)=P(B)P(A,B)​，即“已知 B 发生，A 的概率”。读作“在 B 条件下 A”。
  • 由此得乘法法则 P(A,B)=P(B) P(A∣B)P(A, B) = P(B)\,P(A \mid B)P(A,B)=P(B)P(A∣B)。
  • 贝叶斯公式：
P(A∣B)=P(B∣A) P(A)P(B) P(A \mid B) = \frac{P(B \mid A)\, P(A)}{P(B)} P(A∣B)=P(B)P(B∣A)P(A)​

直觉：贝叶斯是“事后修正”的公式——先有信念 P(A)P(A)P(A)（先验），看到证据 B，按“该证据在 A 下有多常见 P(B∣A)P(B \mid A)P(B∣A)”（似然）修正成 P(A∣B)P(A \mid B)P(A∣B)（后验）。→ 第 4 章 4.3.2 节的 Unigram 分词器用 EM 训练，它的 E 步（用 Viterbi 求每句话的最优切分）本质上就是在推断切分的后验概率——正是“先验（子词概率）× 似然 → 后验”这条路。更广泛地说，“看到数据后如何修正对模型参数的信念”，也就是求 P(参数∣数据)P(\text{参数}\mid\text{数据})P(参数∣数据)，本身就是贝叶斯视角下的机器学习。

0.3.3 期望与方差、独立

  • 期望（expected value）：加权平均，E[X]=∑xx p(x)\mathbb{E}[X] = \sum_x x\, p(x)E[X]=∑x​xp(x)。线性性：E[aX+bY]=a E[X]+b E[Y]\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]E[aX+bY]=aE[X]+bE[Y]（无需独立！）。→ 第 12 章 12.4 节的策略梯度、第 13 章 13.6 节 GRPO 的“组相对优势”，全是对期望求导或做蒙特卡洛估计——线性性正是这些推导能一项项拆开的原因。
  • 方差（variance）：Var(X)=E[(X−E[X])2]\mathrm{Var}(X) = \mathbb{E}\big[(X - \mathbb{E}[X])^2\big]Var(X)=E[(X−E[X])2]，衡量波动大小，方差小 = 估计稳。→ 第 12 章 12.4.3 节讲“为什么要用基线降低方差”。
  • 独立（independent）：P(A,B)=P(A)P(B)P(A, B) = P(A)P(B)P(A,B)=P(A)P(B)，互不影响。注意语言模型里相邻词不独立——这正是语言建模有意思的地方：P(w2∣w1)≠P(w2)P(w_2\mid w_1) \ne P(w_2)P(w2​∣w1​)=P(w2​)。

信息论回答一个问题：“一条消息里到底含有多少信息？”

0.4.1 自信息与熵

直觉：越意外的事，信息量越大。太阳从东边升起（概率≈1）信息量≈0；今天下雪（小概率）信息量很大。把“意外程度”量化：

H(P)=Ex∼P[−log⁡p(x)]=−∑xp(x)log⁡p(x) H(P) = \mathbb{E}_{x \sim P}[-\log p(x)] = -\sum_x p(x) \log p(x) H(P)=Ex∼P​[−logp(x)]=−x∑​p(x)logp(x)

分布越“确定”（某个概率接近 1）熵越低；分布越均匀熵越高。均匀分布在 VVV 个词上的熵是 log⁡V\log VlogV（取 2 为底即 log⁡2V\log_2 Vlog2​V 比特）。→ 第 7 章 7.1 节把损失曲线的不可约下界解释为“数据的熵”，第 2 章 2.4.2 节的困惑度则是熵的指数——两者都以这里为出发点。

定义：真实分布 PPP，我们的模型给出分布 QQQ，交叉熵为

import torch.nn.functional as F

logits = torch.randn(3, 5)          # 模拟 3 个样本、词表大小 5

kl_pq = (p * (p / q).log()).sum()   # D_KL(P||Q)

下面这段代码用 PyTorch 的自动微分把本节的两条公式各验一遍：先用 autograd 逐行求出 softmax 的真雅可比，与我们推的 si(δij−sj)s_i(\delta_{ij}-s_j)si​(δij​−sj​) 对照；再确认交叉熵对 logits 的梯度确实等于“预测概率 − one-hot”。

import torch

z = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
s = torch.softmax(z, dim=-1)

J = torch.zeros(3, 3)                    # 用 autograd 求出真雅可比 J[i,j] = d s_i / d z_j
for i in range(3):
    g = torch.zeros(3); g[i] = 1.0
    J[i] = torch.autograd.grad(s, z, grad_outputs=g, retain_graph=True)[0]

manual = torch.diag(s) - torch.outer(s, s)   # 公式：diag(s) - s s^T，即 s_i(δ_ij - s_j)

0.6 优化：怎么找到下山的最短路

0.6.1 损失函数与梯度下降推导

损失函数（loss function）把“模型有多差”量化成一个数，训练 = 最小化它。梯度下降（gradient descent）的推导只需泰勒展开的一阶直觉：在当前点 xt\mathbf{x}_txt​ 附近，

f(xt+Δx)≈f(xt)+∇f(xt)⊤Δx f(\mathbf{x}_t + \Delta\mathbf{x}) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^\top \Delta\mathbf{x} f(xt​+Δx)≈f(xt​)+∇f(xt​)⊤Δx

想让 fff 下降最多，就要让 ∇f⊤Δx\nabla f^\top \Delta\mathbf{x}∇f⊤Δx 最负。取步子方向为负梯度、长度受学习率 η\etaη 限制，即得更新规则：

xt+1=xt−η ∇f(xt) \mathbf{x}_{t+1} = \mathbf{x}_t - \eta\, \nabla f(\mathbf{x}_t) xt+1​=xt​−η∇f(xt​)

一步能降多少？f(xt+1)≈f(xt)−η∥∇f∥2f(\mathbf{x}_{t+1}) \approx f(\mathbf{x}_t) - \eta \|\nabla f\|^2f(xt+1​)≈f(xt​)−η∥∇f∥2，只要梯度不为零、η\etaη 不太大，就一定在降。

0.6.2 学习率、局部最优与鞍点

  • 学习率 η\etaη 是步长。太大 → 在谷底两侧来回弹甚至发散（loss 尖叫着上升）；太小 → 爬得像蜗牛。→ 第 6 章 6.2 节会讲 warmup + cosine 调度：先热身再退火。
  • 局部最优（local minimum）：周围一个小邻域内最低的点，但不是全局最低。好消息：高维损失面里真正的“坑”反而不多，更多的是——
  • 鞍点（saddle point）：在一个方向上是谷、另一个方向上是脊，形似马鞍。梯度为 0 但不是最优点。大模型损失面上鞍点远多于局部最优，这是训练的主要障碍之一（第 6 章 6.5、6.6 节的梯度裁剪与 loss spike 诊断，就是围绕“稳定下降”做的工程）。直觉：100 亿参数的空间里，要求 100 亿个方向“恰好都朝上”才能困住你，太难了；总有一些方向是下坡。
  • 凸 vs 非凸：凸函数（碗形，任意局部最优即全局最优，如线性回归的损失）；深度网络损失是高度非凸的，没有这种保证，所以训练更像“在山脉中找足够低的谷”，理论和实践都围绕“逃出鞍点、稳定下降”展开。

0.6.3 动量与自适应学习率（预告）

  • 动量（momentum）：把更新想象成有惯性的小球，vt+1=μvt−η∇f\mathbf{v}_{t+1} = \mu \mathbf{v}_t - \eta \nabla fvt+1​=μvt​−η∇f，xt+1=xt+vt+1\mathbf{x}_{t+1} = \mathbf{x}_t + \mathbf{v}_{t+1}xt+1​=xt​+vt+1​。直觉：方向一致时越滚越快（穿过鞍点附近的小平台），方向反复抵消时自动减速（震荡的峡谷里更稳）。
  • 为什么需要自适应学习率：不同参数的梯度量级可以差几个数量级（有的梯度常年 10−810^{-8}10−8，有的 10−210^{-2}10−2），统一学习率对前者太小、对后者太大。自适应方法（AdaGrad/RMSProp/Adam）为每个参数维护自己的步长——用梯度平方的滑动平均来缩放。→ 第 6 章 6.1 节完整推导 Adam/AdamW，此处只埋种子；本章你只需记住：Adam ≈ 动量 + 逐参数自适应步长。

下面这段代码在一个二维玩具函数上跑梯度下降，再用 PyTorch 的自动求导反查我们手写的梯度有没有算错——这是“先手推、再让 autograd 对答案”的标准工作流。

import numpy as np
import torch

def f(x, y):    return (x - 3)**2 + 10 * (y + 2)**2        # 玩具例子：扁长的椭圆谷（见图 0-2）
def grad(x, y): return np.array([2*(x - 3), 20*(y + 2)])   # 手写梯度 (∂f/∂x, ∂f/∂y)

x = np.array([0.0, 0.0])
for step in range(100):
    # 步长取 0.09：y 方向曲率为 20，η·20 = 1.8 > 1，每步都过冲、符号翻转（震荡着收敛）；
    # x 方向曲率只有 2，η·2 = 0.18 ≪ 1，只是慢慢往前挪。两者叠加就是锯齿形。
    x = x - 0.09 * grad(*x)
print(x)                                # 收敛到 [3, -2] 附近

xt = torch.tensor([0.5, -0.5], requires_grad=True)   # 用 autograd 反查手写梯度
f(*xt).backward()
print(xt.grad.numpy(), grad(0.5, -0.5)) # 两行应当一致

0.7.2 上溢、下溢与 softmax 的 max 减技巧

为什么 exp 容易溢出：eze^{z}ez 是爆炸函数。FP64 要涨到 e710≈10308e^{710} \approx 10^{308}e710≈10308 才触顶，FP32 在 e89e^{89}e89 附近就撑不住了；FP16 更窄——e12≈162754>65504e^{12} \approx 162754 > 65504e12≈162754>65504，直接变 inf。而 softmax 的分子分母都是一堆 eze^zez，所以在 FP16 下 logits 只要上到十几就会炸；即便用 FP32，第 3 章 3.2.3 节里未缩放的注意力得分在 dk=128d_k = 128dk​=128 时标准差就有 128≈11\sqrt{128} \approx 11128​≈11，训练早期冲到几十上百也很常见，同样危险。裸写 softmax 必炸，原因就在这里。

softmaxi(z)=ezi−c∑jezj−c,c=max⁡jzj  ⇒  zj−c≤0  ⇒  ezj−c≤1 \text{softmax}_i(\mathbf{z}) = \frac{e^{z_i - c}}{\sum_j e^{z_j - c}}, \qquad c = \max_j z_j \;\Rightarrow\; z_j - c \le 0 \;\Rightarrow\; e^{z_j - c} \le 1 softmaxi​(z)=∑j​ezj​−cezi​−c​,c=jmax​zj​⇒zj​−c≤0⇒ezj​−c≤1
