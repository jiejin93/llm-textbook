第 0 章 面向大模型的数学基础（线性代数·概率·微积分·优化）

这一章是为”只学过大学高数上册”的读者准备的前置数学补丁。后面 17 章里出现的几乎所有数学——从第 3 章注意力的点积、到第 6 章混合精度的浮点溢出、再到第 13 章 RLHF 里的 KL 约束——都建立在本章的概念之上。我们把它们按”依赖顺序”一次性讲清：先学会看符号（0.1），再学线性代数（0.2）和概率（0.3），它们合起来支撑信息论（0.4）与微积分（0.5），最后汇入优化（0.6）和数值表示（0.7）。

每一节的结构都是固定的：直觉 → 形式定义 → 后文哪里用到 → 可运行代码 → 延伸阅读。你不必先读完本章再读第 1 章——它更像一本随查字典，但从头到尾读一遍大约需要 4~6 小时，读完后再看第 3 章、第 12–13 章会顺畅得多。

0.2 线性代数：向量、矩阵与张量

0.2.1 向量：一串数字，也是一个点

直觉：向量（vector）就是一列有序的数，比如 x=(x1,x2,…,xd)∈Rd\mathbf{x} = (x_1, x_2, \ldots, x_d) \in \mathbb{R}^dx=(x1​,x2​,…,xd​)∈Rd。它有两种等价的看法：一是一支从原点出发的箭头（有方向有长度），二是 ddd 维空间里的一个点。大模型里，”猫”这个词在模型眼中就是一个几千维的向量——语义被编码成了空间中的位置。

定义：ddd 维实数向量空间 Rd\mathbb{R}^dRd 中的元素。向量可以相加（对应分量相加）、可以数乘（每个分量乘同一个数）。

0.2.2 点积：相似度的度量

两个同维向量 q\mathbf{q}q 和 k\mathbf{k}k 的点积（dot product，内积）：

q⋅k=∑i=1dqiki=∥q∥ ∥k∥cos⁡θ \mathbf{q} \cdot \mathbf{k} = \sum_{i=1}^{d} q_i k_i = \|\mathbf{q}\| \, \|\mathbf{k}\| \cos\theta q⋅k=i=1∑d​qi​ki​=∥q∥∥k∥cosθ

其中 θ\thetaθ 是两向量的夹角。直觉：点积衡量”两个向量有多一致”。方向相同 → 点积大且为正；垂直（无关）→ 为 0；相反 → 为负。在词向量空间里，”国王 · 女王” 远大于 “国王 · 洗衣机”。

→ 后文哪里用到：这就是第 3 章注意力机制的引擎——注意力分数 score(q,k)=q⋅kd\text{score}(q, k) = \frac{q \cdot k}{\sqrt{d}}score(q,k)=d​q⋅k​，本质是”查询词 q 与每个词的键 k 做点积，看谁跟我最相关”。第 16 章 CLIP 的图文相似度也是点积。看懂本小节，第 3 章的公式就懂了一半。

0.2.3 矩阵乘法及其复杂度

直觉：矩阵（matrix）是一个 m×nm \times nm×n 的数表。矩阵乘法 C=ABC = ABC=AB（AAA 是 m×km \times km×k，BBB 是 k×nk \times nk×n）可以理解为”对 B 的每一列分别做一次线性组合”，也可以理解为”批量做点积”：cij=∑l=1kailbljc_{ij} = \sum_{l=1}^{k} a_{il} b_{lj}cij​=∑l=1k​ail​blj​，即 CCC 的第 iii 行第 jjj 列是 AAA 的第 iii 行与 BBB 的第 jjj 列的点积。

Cij=∑l=1kAilBlj,C∈Rm×n C_{ij} = \sum_{l=1}^{k} A_{il} B_{lj}, \qquad C \in \mathbb{R}^{m \times n} Cij​=l=1∑k​Ail​Blj​,C∈Rm×n

注意形状规则：(m×k)×(k×n)=(m×n)(m \times k) \times (k \times n) = (m \times n)(m×k)×(k×n)=(m×n)，内侧两个维度必须相等——写代码报维度错误时，先检查这个。

复杂度：每个 cijc_{ij}cij​ 要做 kkk 次乘加，共 m×nm \times nm×n 个元素，所以是 O(m⋅k⋅n)O(m \cdot k \cdot n)O(m⋅k⋅n)。特例：两个 n×nn \times nn×n 方阵相乘是 O(n3)O(n^3)O(n3)。→ 第 3 章：注意力中 QK⊤QK^\topQK⊤ 是 (n×d)×(d×n)(n \times d) \times (d \times n)(n×d)×(d×n)，复杂度 O(n2d)O(n^2 d)O(n2d)，nnn 是序列长度——这个平方就是”长上下文贵”的根源，也是第 14 章 FlashAttention 要优化的对象。

0.2.4 转置、范数、单位矩阵与逆、特征值（速览）

  • 转置 A⊤A^\topA⊤：行列互换，Aij⊤=AjiA^\top_{ij} = A_{ji}Aij⊤​=Aji​。性质 (AB)⊤=B⊤A⊤(AB)^\top = B^\top A^\top(AB)⊤=B⊤A⊤（顺序翻转！）。→ 第 3 章 QK⊤QK^\topQK⊤、第 10 章 LoRA 的 BAB ABA。
  • 范数 ∥x∥p=(∑i∣xi∣p)1/p\|\mathbf{x}\|_p = \left(\sum_i |x_i|^p\right)^{1/p}∥x∥p​=(∑i​∣xi​∣p)1/p。最常用 p=2p=2p=2（欧氏长度）和 p=1p=1p=1（绝对值之和，第 6 章/第 10 章正则化里限制参数大小用它）。归一化 = 除以范数，让长度变成 1。
  • 单位矩阵 III：对角线为 1 其余为 0，满足 AI=AAI = AAI=A，相当于数的 1。逆矩阵 A−1A^{-1}A−1 满足 A−1A=IA^{-1}A = IA−1A=I，相当于”除法”，概念了解即可——深度学习几乎从不显式求逆（数值不稳定且 O(n3)O(n^3)O(n3)），总是解方程或用梯度。
  • 特征值（一句话）：Av=λvA\mathbf{v} = \lambda \mathbf{v}Av=λv，λ\lambdaλ 是”被这个矩阵拉伸后方向不变只变长度”的倍数；它刻画矩阵的”最大拉伸能力”。→ 第 3 章位置编码、第 10 章初始化分析中会再次露面，届时再展开。

0.2.5 PyTorch 张量与广播

张量（tensor）是向量的推广：0 阶=标量，1 阶=向量，2 阶=矩阵，3 阶以上=张量。一批句子的词向量堆在一起就是形状 (batch, seq_len, d_model) 的 3 阶张量。广播（broadcasting）是 numpy/PyTorch 的对齐规则：形状不同的张量运算时，维度从右往左对齐，长度为 1 的维度自动”复制”到与另一方相同。→ 第 3 章多头注意力的 mask、第 8 章分布式里的 per-device 缩放，全靠广播。

import torch

# 向量、点积、矩阵乘法
q = torch.tensor([1.0, 2.0, 3.0])
k = torch.tensor([4.0, 0.0, 1.0])
print(torch.dot(q, k))            # 7.0  = 1*4 + 2*0 + 3*1

# 注意力的雏形：4 个 token，每个 3 维
Q = torch.randn(4, 3)             # 形状 (n=4, d=3)
K = torch.randn(4, 3)
scores = Q @ K.transpose(-2, -1)  # (4,3) @ (3,4) -> (4,4)，token 两两点积
print(scores.shape)               # torch.Size([4, 4])

# 范数与归一化（第 3 章注意力里 Softmax 前的缩放、第 13 章都有出现）
print(torch.norm(q))              # sqrt(1+4+9) = 3.7417

# 广播：(4,3) + (3,) -> (3,) 被复制 4 份
print((Q + q).shape)              # torch.Size([4, 3])

0.3 概率论：不确定性的语言

0.3.1 随机变量与概率分布

直觉：随机变量（random variable）是”还没揭晓的数”——掷骰子的点数、模型下一个要生成的词。概率分布（probability distribution）给每个可能的结果分配一个 0 到 1 的权重，所有权重加起来等于 1。语言模型本质上就是一台机器：输入前文，输出”下一个词的概率分布”。

定义：离散随机变量 XXX 取值 xxx 的概率记 P(X=x)P(X = x)P(X=x)（简写 p(x)p(x)p(x)），满足 p(x)≥0p(x) \ge 0p(x)≥0 且 ∑xp(x)=1\sum_x p(x) = 1∑x​p(x)=1。

0.3.2 联合、条件概率与贝叶斯

  • 联合概率 P(A,B)P(A, B)P(A,B)：两件事同时发生的概率。
  • 条件概率：P(A∣B)=P(A,B)P(B)P(A \mid B) = \dfrac{P(A, B)}{P(B)}P(A∣B)=P(B)P(A,B)​，即”已知 B 发生，A 的概率”。读作”在 B 条件下 A”。
  • 由此得乘法法则 P(A,B)=P(B) P(A∣B)P(A, B) = P(B)\,P(A \mid B)P(A,B)=P(B)P(A∣B)。
  • 贝叶斯公式：
P(A∣B)=P(B∣A) P(A)P(B) P(A \mid B) = \frac{P(B \mid A)\, P(A)}{P(B)} P(A∣B)=P(B)P(B∣A)P(A)​

直觉：贝叶斯是”事后修正”的公式——先有信念 P(A)P(A)P(A)（先验），看到证据 B，按”该证据在 A 下有多常见 P(B∣A)P(B \mid A)P(B∣A)”修正成 P(A∣B)P(A \mid B)P(A∣B)（后验）。→ 第 4 章 Unigram 分词器的迭代就依赖它；更广泛地，”模型参数给定数据”的机器学习视角本身就是贝叶斯式的。

0.3.3 期望与方差、独立

  • 期望（expected value）：加权平均，E[X]=∑xx p(x)\mathbb{E}[X] = \sum_x x\, p(x)E[X]=∑x​xp(x)。线性性：E[aX+bY]=a E[X]+b E[Y]\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]E[aX+bY]=aE[X]+bE[Y]（无需独立！）。→ 第 12 章策略梯度、第 13 章 GRPO 的”组相对优势”全是对期望求导/估计。
  • 方差（variance）：Var(X)=E[(X−E[X])2]\mathrm{Var}(X) = \mathbb{E}\big[(X - \mathbb{E}[X])^2\big]Var(X)=E[(X−E[X])2]，衡量波动大小，方差小 = 估计稳。→ 第 12 章讲”为什么要用基线降低方差”。
  • 独立（independent）：P(A,B)=P(A)P(B)P(A, B) = P(A)P(B)P(A,B)=P(A)P(B)，互不影响。注意语言模型里相邻词不独立——这正是语言建模有意思的地方。

0.3.4 链式法则：语言模型的灵魂公式

把 0.3.2 的乘法法则反复使用，任意联合概率可以拆成一串条件概率的连乘：

P(w1,w2,…,wn)=∏i=1nP(wi∣w1,…,wi−1)=∏i=1nP(wi∣w<i) P(w_1, w_2, \ldots, w_n) = \prod_{i=1}^{n} P(w_i \mid w_1, \ldots, w_{i-1}) = \prod_{i=1}^{n} P(w_i \mid w_{<i}) P(w1​,w2​,…,wn​)=i=1∏n​P(wi​∣w1​,…,wi−1​)=i=1∏n​P(wi​∣w<i​)

推导（对 n=3n=3n=3 验证）：P(w1,w2,w3)=P(w1) P(w2,w3∣w1)=P(w1) P(w2∣w1) P(w3∣w1,w2)P(w_1, w_2, w_3) = P(w_1)\,P(w_2, w_3 \mid w_1) = P(w_1)\,P(w_2 \mid w_1)\,P(w_3 \mid w_1, w_2)P(w1​,w2​,w3​)=P(w1​)P(w2​,w3​∣w1​)=P(w1​)P(w2​∣w1​)P(w3​∣w1​,w2​)。归纳即得一般形式。

直觉：一句话出现的概率 = “第 1 个词的概率 × 已知第 1 个词后第 2 个词的概率 × ……”。→ 第 2 章整章建立在这条公式上：语言模型训练就是最大化它（的对数），生成就是沿着它自回归地往前走；第 14 章的 KV Cache、投机解码也是在加速这个逐词过程。

0.3.5 采样

直觉：从分布里”抽签”。greedy 是永远抽最大那个（会啰嗦重复），temperature 是先把 logits 除以 TTT 再 softmax（TTT 小 → 分布尖，TTT 大 → 分布平），top-k/top-p 是先砍掉小概率再抽。→ 第 2 章采样策略一节详细展开，那里会逐个实现。

import torch

# 一个"下一个词"的分布：模拟 P(w | "今天天气真")
logits = torch.tensor([2.0, 1.0, 0.5, -1.0])
probs = torch.softmax(logits, dim=-1)
print(probs)                       # tensor([0.61, 0.22, 0.14, 0.03]) 附近

# 链式法则演示：P(今天, 天气) = P(今天) * P(天气|今天)
p_today = torch.tensor(0.01)
p_weather_given_today = torch.tensor(0.05)
print((p_today * p_weather_given_today).item())   # 0.0005，连乘多了就会下溢 -> 这就是为什么要取 log

# 从分布中采样（第 2 章 temperature 采样的雏形）
samples = torch.multinomial(probs, num_samples=1000, replacement=True)
print(torch.bincount(samples) / 1000.0)           # 频率近似概率，越接近 probs 越好

0.4 信息论：熵、交叉熵、KL 散度

信息论回答一个问题：”一条消息里到底含有多少信息？”

0.4.1 自信息与熵

直觉：越意外的事，信息量越大。太阳从东边升起（概率≈1）信息量≈0；今天下雪（小概率）信息量很大。把”意外程度”量化：

自信息(x)=−log⁡p(x) \text{自信息}(x) = -\log p(x) 自信息(x)=−logp(x)

概率 1 → 自信息 0；概率减半 → 自信息加 1（log⁡2≈0.693\log 2 \approx 0.693log2≈0.693，以 2 为底时恰好是 1 比特）。取对数还保证了独立事件信息量可加。

熵（entropy）是自信息的期望，即”平均意外程度”：

H(P)=Ex∼P[−log⁡p(x)]=−∑xp(x)log⁡p(x) H(P) = \mathbb{E}_{x \sim P}[-\log p(x)] = -\sum_x p(x) \log p(x) H(P)=Ex∼P​[−logp(x)]=−x∑​p(x)logp(x)

分布越”确定”（一个概率接近 1）熵越低；分布越均匀熵越高。均匀分布 over VVV 个词的熵是 log⁡V\log VlogV（取 2 为底即 log⁡2V\log_2 Vlog2​V 比特）。→ 第 7 章讨论模型能力上限、第 2 章困惑度的定义，都以熵为出发点。

0.4.2 交叉熵：用错误的分布给真实数据编码

定义：真实分布 PPP，我们的模型给出分布 QQQ，交叉熵为

H(P,Q)=−∑xp(x)log⁡q(x) H(P, Q) = -\sum_x p(x) \log q(x) H(P,Q)=−x∑​p(x)logq(x)

直觉：数据其实来自 PPP，但我们用 QQQ 当”编码本”去编码它。如果 QQQ 把概率给了错误的地方（ppp 大的地方 qqq 小），−log⁡q-\log q−logq 就很大，交叉熵就高。最重要的恒等式（展开即得）：

H(P,Q)=H(P)+DKL(P ∥ Q)≥H(P) H(P, Q) = H(P) + D_{\mathrm{KL}}(P \,\|\, Q) \ge H(P) H(P,Q)=H(P)+DKL​(P∥Q)≥H(P)

交叉熵 = 数据本身的熵（不可约的部分）+ 我们犯的错（KL 散度）。训练语言模型时 H(P)H(P)H(P) 是常数，所以最小化交叉熵 = 最小化 KL = 让模型分布贴近真实分布。→ 第 2 章训练目标 loss = -log P(下一个词 | 前文) 正是交叉熵在”每步只有一个正确词”情形下的特例（此时 H(P,Q)H(P,Q)H(P,Q) 退化为 −log⁡q(w∗)-\log q(w^*)−logq(w∗)）；第 13 章奖励模型排名损失也是其变体。

0.4.3 KL 散度：两个分布差多远，且不对称

DKL(P ∥ Q)=∑xp(x)log⁡p(x)q(x)≥0 D_{\mathrm{KL}}(P \,\|\, Q) = \sum_x p(x) \log \frac{p(x)}{q(x)} \ge 0 DKL​(P∥Q)=x∑​p(x)logq(x)p(x)​≥0

两个关键性质：

  1. 非负（吉布斯不等式），且当且仅当 P=QP = QP=Q 处处相等时取 0。直觉：平均对数似然比 EP[log⁡(p/q)]\mathbb{E}_P[\log(p/q)]EP​[log(p/q)]，p>qp>qp>q 的地方被 ppp 加权放大。
  2. 不对称：DKL(P∥Q)≠DKL(Q∥P)D_{\mathrm{KL}}(P\|Q) \ne D_{\mathrm{KL}}(Q\|P)DKL​(P∥Q)=DKL​(Q∥P)！直觉：DKL(P∥Q)D_{\mathrm{KL}}(P\|Q)DKL​(P∥Q)（前向 KL）惩罚”真实分布有概率、模型却给零概率”的地方——于是 QQQ 被迫覆盖 PPP 的每个角落（mass-covering）；DKL(Q∥P)D_{\mathrm{KL}}(Q\|P)DKL​(Q∥P)（反向 KL）只惩罚”模型给了概率而真实分布没有”的地方——于是 QQQ 倾向收缩到 PPP 的某个峰上（mode-seeking）。

→ 第 13 章 RLHF 的 PPO 目标里有一项 β DKL(πθ∥πref)\beta\, D_{\mathrm{KL}}(\pi_\theta \| \pi_{\text{ref}})βDKL​(πθ​∥πref​)：允许策略向高奖励移动，但每个 token 都不能偏离参考模型太远，否则奖励被劫持。第 9 章 MoE 的负载均衡损失也是”让专家分布接近均匀”的 KL 形式。第 16 章 CLIP/InfoNCE 里也有它的身影。

0.4.4 困惑度

困惑度（perplexity, PPL）是交叉熵的指数：

PPL=2H(以 2 为底)或PPL=eL  ，其中 L=−1n∑i=1nlog⁡p(wi∣w<i) \mathrm{PPL} = 2^{H} \quad (\text{以 2 为底}) \qquad \text{或} \qquad \mathrm{PPL} = e^{L} \; \text{，其中 } L = -\frac{1}{n}\sum_{i=1}^{n} \log p(w_i \mid w_{<i}) PPL=2H(以 2 为底)或PPL=eL，其中 L=−n1​i=1∑n​logp(wi​∣w<i​)

直觉：困惑度 = “模型每一步在多少个词之间犹豫”。PPL = 1 是完美预测；PPL = 100 意味着平均而言像在 100 个词里均匀猜。因为指数是单调的，最小化交叉熵损失 ⇔ 最小化困惑度。→ 第 2 章正式定义、第 11 章评测、第 7 章 Scaling Laws 的 L^\hat LL^ 全用它。

import torch
import torch.nn.functional as F

# 手写交叉熵：模拟 3 个样本、词表 5，正确词 id 分别是 [0, 2, 4]
logits = torch.randn(3, 5)
target = torch.tensor([0, 2, 4])

log_probs = F.log_softmax(logits, dim=-1)          # log q(x)，数值稳定的做法（见 0.7 节）
mine = -log_probs[torch.arange(3), target].mean()  # H = -mean log q(正确词)
ref = F.cross_entropy(logits, target)              # PyTorch 官方实现
print(mine.item(), ref.item())                     # 两者应完全一致

# KL 散度的不对称性
p = torch.tensor([0.9, 0.1])
q = torch.tensor([0.5, 0.5])
kl_pq = (p * (p / q).log()).sum()   # D_KL(P||Q)
kl_qp = (q * (q / p).log()).sum()   # D_KL(Q||P)
print(kl_pq.item(), kl_qp.item())   # 0.37 vs 0.51 —— 顺序不同结果不同！

导数是”输入动一点点，输出动多少”：

ddxf(g(x))=f′(g(x))⋅g′(x) \frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x) dxd​f(g(x))=f′(g(x))⋅g′(x)

0.5.2 梯度、雅可比

多元函数 f:Rd→Rf: \mathbb{R}^d \to \mathbb{R}f:Rd→R（输入向量、输出一个数——损失函数正是这种形状），梯度（gradient）是把所有偏导排成向量：

直觉：站在山坡上，梯度指向”上坡最陡的方向”，模长是那个方向的坡度。训练就是沿 −∇f-\nabla f−∇f 下坡。

若输出也是向量 f:Rn→Rmf: \mathbb{R}^n \to \mathbb{R}^mf:Rn→Rm，所有偏导排成的 m×nm \times nm×n 矩阵叫雅可比矩阵（Jacobian），Jij=∂fi/∂xjJ_{ij} = \partial f_i / \partial x_jJij​=∂fi​/∂xj​。直觉：它就是向量版的导数，”每个输入分量如何影响每个输出分量”。反向传播每过一层，就把上游梯度乘上该层的雅可比。了解直觉即可，本书不需要手算大雅可比。

0.5.5 数值梯度验证

不确定自己推的公式对不对？用定义 ∂f∂x≈f(x+h)−f(x−h)2h\frac{\partial f}{\partial x} \approx \frac{f(x+h) - f(x-h)}{2h}∂x∂f​≈2hf(x+h)−f(x−h)​（中心差分，误差 O(h2)O(h^2)O(h2)）直接数值验证。这是深度学习工程师的看家本领。

import torch

# 验证 softmax 雅可比公式 d s_i / d z_j = s_i (delta_ij - s_j)
z = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
s = torch.softmax(z, dim=-1)

J = torch.zeros(3, 3)
for i in range(3):                       # 对 s 的每个分量反向求梯度
    g = torch.zeros(3); g[i] = 1.0
    J[i] = torch.autograd.grad(s, z, grad_outputs=g, retain_graph=True)[0]  # J[i,j] = d s_i / d z_j

manual = torch.diag(s) - torch.outer(s, s)   # 公式: diag(s) - s s^T
print((J - manual).abs().max().item())   # ~1e-9，公式正确

# 验证“交叉熵 + softmax 的梯度 = 预测 - onehot”
logits = torch.randn(5, requires_grad=True)
target = torch.tensor(2)
loss = torch.nn.functional.cross_entropy(logits, target)
loss.backward()
print(logits.grad)                                        # 手写梯度:
print(torch.softmax(logits, -1) - torch.nn.functional.one_hot(target, 5).float())

0.6 优化：怎么找到下山的最短路

0.6.1 损失函数与梯度下降推导

损失函数（loss function）把”模型有多差”量化成一个数，训练 = 最小化它。梯度下降（gradient descent）的推导只需泰勒展开的一阶直觉：在当前点 xt\mathbf{x}_txt​ 附近，

f(xt+Δx)≈f(xt)+∇f(xt)⊤Δx f(\mathbf{x}_t + \Delta\mathbf{x}) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^\top \Delta\mathbf{x} f(xt​+Δx)≈f(xt​)+∇f(xt​)⊤Δx

想让 fff 下降最多，就要让 ∇f⊤Δx\nabla f^\top \Delta\mathbf{x}∇f⊤Δx 最负。取步子方向为负梯度、长度受学习率 η\etaη 限制，即得更新规则：

xt+1=xt−η ∇f(xt) \mathbf{x}_{t+1} = \mathbf{x}_t - \eta\, \nabla f(\mathbf{x}_t) xt+1​=xt​−η∇f(xt​)

一步能降多少？f(xt+1)≈f(xt)−η∥∇f∥2f(\mathbf{x}_{t+1}) \approx f(\mathbf{x}_t) - \eta \|\nabla f\|^2f(xt+1​)≈f(xt​)−η∥∇f∥2，只要梯度不为零、η\etaη 不太大，就一定在降。

0.6.2 学习率、局部最优与鞍点

  • 学习率 η\etaη 是步长。太大 → 在谷底两侧来回弹甚至发散（loss 尖叫着上升）；太小 → 爬得像蜗牛。→ 第 6 章会讲 warmup + cosine 调度：先热身再退火。
  • 局部最优（local minimum）：周围一个小邻域内最低的点，但不是全局最低。好消息：高维损失面里真正的”坑”反而不多，更多的是——
  • 鞍点（saddle point）：在一个方向上是谷、另一个方向上是脊，形似马鞍。梯度为 0 但不是最优点。大模型损失面上鞍点远多于局部最优，这是训练的主要障碍之一。直觉：100 亿参数的空间里，要求 100 亿个方向”恰好都朝上”才能困住你，太难了；总有一些方向是下坡。
  • 凸 vs 非凸：凸函数（碗形，任意局部最优即全局最优，如线性回归的损失）；深度网络损失是高度非凸的，没有这种保证，所以训练更像”在山脉中找足够低的谷”，理论和实践都围绕”逃出鞍点、稳定下降”展开。

0.6.3 动量与自适应学习率（预告）

  • 动量（momentum）：把更新想象成有惯性的小球，vt+1=μvt−η∇f\mathbf{v}_{t+1} = \mu \mathbf{v}_t - \eta \nabla fvt+1​=μvt​−η∇f，xt+1=xt+vt+1\mathbf{x}_{t+1} = \mathbf{x}_t + \mathbf{v}_{t+1}xt+1​=xt​+vt+1​。直觉：方向一致时越滚越快（穿过鞍点附近的小平台），方向反复抵消时自动减速（震荡的峡谷里更稳）。
  • 为什么需要自适应学习率：不同参数的梯度量级可以差几个数量级（有的梯度常年 10−810^{-8}10−8，有的 10−210^{-2}10−2），统一学习率对前者太小、对后者太大。自适应方法（AdaGrad/RMSProp/Adam）为每个参数维护自己的步长——用梯度平方的滑动平均来缩放。→ 第 6 章完整推导 Adam/AdamW，此处只埋种子；本章你只需记住：Adam ≈ 动量 + 逐参数自适应步长。
import numpy as np
import torch

# 玩具例子：f(x, y) = (x-3)^2 + 10(y+2)^2，一个椭圆谷（见下方等高线图）
def f(x, y):  return (x - 3)**2 + 10 * (y + 2)**2
def grad(x, y): return np.array([2*(x - 3), 20*(y + 2)])

x = np.array([0.0, 0.0])
for step in range(100):                 # 普通梯度下降
    x = x - 0.04 * grad(*x)
print(x)                                # 收敛到 [3, -2] 附近

# 用 torch 自动求导验证我们手写的梯度没算错
xt = torch.tensor([0.5, -0.5], requires_grad=True)
f(*xt).backward()
print(xt.grad.numpy(), grad(0.5, -0.5)) # 两行应当一致

0.7 数值表示：浮点数与溢出

0.7.1 IEEE 754：计算机如何存小数

计算机用有限位二进制存小数，标准是 IEEE 754。一个浮点数分三段：符号位 sss、指数位、尾数位（mantissa/fraction），值为

value=(−1)s×1.m×2e \text{value} = (-1)^s \times 1.m \times 2^{e} value=(−1)s×1.m×2e

直觉：科学计数法的二进制版。1.m1.m1.m 像有效数字（尾数位越多，精度越高），指数决定小数点位置（指数位越多，能表示的范围越大）。精度与范围是一对此消彼长的资源——这是 FP16/BF16 取舍的全部秘密。

三种常见格式的对比（FP16 最小正规数按 2−142^{-14}2−14 计）：

格式 符号 指数 尾数 最大值 最小正规数 有效十进制位
FP32 1 8 23 ≈3.4×1038\approx 3.4\times10^{38}≈3.4×1038 ≈1.2×10−38\approx 1.2\times10^{-38}≈1.2×10−38 ~7
FP16 1 5 10 65504 ≈6.1×10−5\approx 6.1\times10^{-5}≈6.1×10−5 ~3
BF16 1 8 7 ≈3.4×1038\approx 3.4\times10^{38}≈3.4×1038 ≈1.2×10−38\approx 1.2\times10^{-38}≈1.2×10−38 ~2

0.7.2 上溢、下溢与 softmax 的 max 减技巧

为什么 exp 容易溢出：eze^{z}ez 是爆炸函数。e710≈10308e^{710} \approx 10^{308}e710≈10308 就到了 FP64 的极限；FP16 下 e12≈162754>65504e^{12} \approx 162754 > 65504e12≈162754>65504，直接 inf。而 softmax 分子分母都是一堆 eze^zez，训练早期 logits 轻轻松松上几十，裸写必炸。

减去最大值后所有指数都不超过 0，eee 的结果都在 (0,1](0, 1](0,1]，永不上溢；分母至少有一项为 1，也不会因为全下溢而除零。这就是 0.4 节代码里 F.log_softmax 背后干的事。

import torch

z = torch.tensor([500.0, 501.0, 502.0])

# 裸写 softmax：溢出
naive = torch.exp(z) / torch.exp(z).sum()
print(naive)   # tensor([nan, nan, nan]) —— exp(500) = inf，inf/inf = nan

# max 减技巧：稳定
c = z.max()
stable = torch.exp(z - c) / torch.exp(z - c).sum()
print(stable)                              # 正常的概率分布
print(torch.allclose(stable, torch.softmax(z, dim=-1)))  # True，与官方一致
